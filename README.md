# mol-craft

설치·로그인·서버 없이 브라우저에서 도는 분자 조립 + UFF 역장 분석 도구.

## 실행

```bash
python3 -m http.server 8000   # 또는 아무 정적 서버
# http://localhost:8000
```

빌드 단계도 npm 의존성도 없다. `index.html`을 그대로 서빙하면 된다.

## 조작법

도구(툴바)가 클릭 동작을 결정한다. 학습/연구 모드와는 무관하다 — 연구 모드에서도 조립하고,
학습 모드에서도 측정할 수 있다.

| 도구 | 클릭 | 동작 |
|---|---|---|
| **선택** (기본) | 원자 클릭 | 단일 선택. Shift+클릭은 추가/제외 토글. 빈 공간 드래그는 박스 선택 |
| **붙이기** (원소 팔레트 클릭 시 자동 전환) | — | 원자 위에 커서를 올리면 그 자리에 실제로 붙을 위치가 반투명 구로 깜빡이며 미리 보인다. 클릭하면 그 자리에 붙는다 |
| **지우개** | 원자 클릭 | 그 원자를 뗀다 |

- **결합 각도:** 새 원자는 항상 그 중심의 목표 VSEPR 형상에 맞는 방향에만 붙는다(직선 180° · 평면삼각형 120° · 정사면체 109.47°). 목표는 **결합 개수가 아니라 전자 도메인 수**(결합 자리 + 비공유 전자쌍)로 잡는다 — 그래서 물(O)은 첫 H 두 개부터 109.47° 방향으로 붙고, 암모니아(N)도 세 번째 H까지 109.47°로 붙는다. 결합 개수만 셌다면 물이 180°(선형)로 붙어버리고, 그 대칭 위치는 UFF 힘이 정확히 0이라 최적화로도 못 빠져나온다. 미리보기가 곧 실제 결과다.
- **불안정해도 일단 붙는다:** 원자가를 넘는 결합(옥텟 초과)도 이제 막지 않는다. 미리보기 구 색으로 미리 알 수 있다 — **초록**=정상, **주황**=초원자가/원자가 초과(그래도 붙음), **빨강**=아예 못 붙음(자기 자신·이미 결합됨·미지원 원소 등 데이터 모델상 불가능한 경우뿐). 붙인 뒤에는 안정도 HUD가 계속 경고를 띄운다.
- **키보드:** `Ctrl+A` 전체 선택 · `Esc` 선택 해제 · `Del`/`Backspace` 선택 삭제 · `Ctrl+D` 선택 복제 · `Ctrl+Z` 실행취소(최근 20단계).
- **마우스 휠:** 확대/축소(위로 굴리면 확대 — 일반적인 방향).
- **드래그:** 빈 공간이면 회전(선택 도구는 박스 선택으로 바뀜).
- **2D 보기(골격 구조식):** 수소를 숨기고(결합선도 함께 사라짐) 탄소는 꼭짓점으로만, 헤테로원자는 문자 라벨로 표시한다. 원근도 없애 정사영으로 본다. 실좌표를 그대로 정사영한 것이라 화학 교과서의 자동 골격도 생성기(지그재그 배치)는 아니다 — 카메라를 분자 평면에 자동으로 맞추지도 않으므로, 원하는 면이 보이도록 드래그로 돌린 다음 누르면 된다.
- **이면각 직접 회전:** 원자 4개를 순서대로 선택하면 "이면각 회전" 슬라이더가 활성화된다. 슬라이더를 움직이면 그 결합을 기준으로 구조가 실시간으로 회전한다. 고리에 속한 결합은 회전할 수 없다(비활성 표시).
- **이면각 스캔:** 원자 4개 선택 후 "이면각 스캔". 스텝 각도(5/10/15/30°)와 완화 스캔(각 각도에서 나머지 구조를 재최적화, 느리지만 더 정확) 여부를 직접 고른다.
- **그리드:** 헤더의 "그리드" 체크박스로 배경 3D 참조 격자(정육면체 6면)를 켜고 끈다. 분자와 무관한 고정 배경이라 조립·측정 중에는 다시 그려지지 않는다(조작감 저하 방지).
- **안정도 HUD:** 뷰어 좌상단에 0~100 점수와 문제 원자 칩이 뜬다. `▲`는 경고(VSEPR 편차·초원자가), `✕`(깜빡임)는 심각한 편차(원자가 초과 등). 점수·색·모양으로 삼중 확인 가능.

## 학습 모드 vs 연구 모드

도구는 공통이고, 모드는 패널 노출과 조립 후 동작만 바꾼다.

- **학습 모드:** 원자를 붙일 때마다 자동으로 UFF 최적화가 돌아 바로 자리를 잡는다. VSEPR 형상을 완성하면 소리와 토스트로 알려준다.
- **연구 모드:** 붙여도 자동 최적화하지 않는다(직접 "구조 최적화"를 눌러야 함). 항별 에너지 분해, 최적화 리플레이 슬라이더 등 분석 패널이 추가로 보인다.

## 테스트

```bash
node --test
```

`test/validation.test.js`가 문헌값(정사면체 109.47°, 에탄 회전장벽, 의자<보트)을 검증한다.
이 테스트가 깨지면 물리 결과를 신뢰하지 말 것.

## 물리 모델과 한계

- **역장:** UFF (Rappé et al., *JACS* **1992**, 114, 10024). 결합 신축 · 결합각 · 비틀림 · 반데르발스 4개 항.
- **포함하지 않는 것:** 정전기(부분전하) 항, 용매 효과, 전자 상관, 여기 상태. 전부 진공 기준.
- **신뢰 구간:** 2주기 유기 분자의 배좌 비교와 상대 에너지 경향은 정성적으로 유효하다.
  초원자가(PCl₅ 등)와 전이금속은 UFF가 축/적도 위치를 구분하지 못하므로 **정량 해석 불가**.
- **양자계산 대체가 아니다.** 반응 에너지, pKa, 전이상태에는 사용할 수 없다.

## 배포

GitHub Pages. **빌드 단계 없음** — 저장소 루트를 그대로 서빙한다.

1. GitHub → Settings → Pages
2. Source: `Deploy from a branch`
3. Branch: `main`, 폴더 `/ (root)` → Save
4. 1~2분 뒤 `https://<owner>.github.io/mol-craft/` 에서 열린다

CI(`.github/workflows/test.yml`)는 push/PR마다 `node --test`를 돌린다.
물리 검증 스위트가 빨간불이면 배포된 수치를 믿지 말 것.

## 저장과 공유

- **자동 저장:** `localStorage`(키 `molcraft:last`). 새로고침해도 마지막 구조가 복원된다.
- **링크 공유:** URL 해시(`#s=...`)에 구조를 담는다. 서버를 거치지 않으므로 영구히 유효하다.
  진입 시 우선순위는 URL 해시 > localStorage > 기본 프리셋이다.
- **단축 링크 / 공개 갤러리 (선택):** Supabase에 익명으로 저장한다. `src/config.js`가 비어 있으면
  이 기능만 꺼지고 나머지는 전부 동작한다. 무료 티어 프로젝트는 비활동 시 일시정지되므로
  **단축 링크는 영구 보관을 보장하지 않는다.** 영구 링크가 필요하면 해시 링크(`#s=`)를 쓸 것.
