# mol-craft

설치·로그인·서버 없이 브라우저에서 도는 분자 조립 + UFF 역장 분석 도구.

## 실행

```bash
python3 -m http.server 8000   # 또는 아무 정적 서버
# http://localhost:8000
```

빌드 단계도 npm 의존성도 없다. `index.html`을 그대로 서빙하면 된다.

## 조작법

| 동작 | 학습 모드 | 연구 모드 |
|---|---|---|
| 원자 클릭 | 선택한 원소를 붙인다(레고처럼 VSEPR 이상각에 자동으로 물린다) | 측정용으로 선택(최대 4개, 5번째 클릭 시 초기화) |
| Shift + 클릭 | 그 원자를 뗀다 | — |
| 마우스 휠 | 확대/축소(위로 굴리면 확대) | 동일 |
| 드래그 | 회전 | 동일 |

- **결합 각도:** 새 원자는 항상 그 중심의 목표 VSEPR 형상(직선 180° · 평면삼각형 120° · 정사면체 109.47° 등)에 맞는 방향에만 붙는다. 임의 각도로 붙지 않는다.
- **이면각 직접 회전:** 원자 4개(연구 모드에서)를 순서대로 선택하면 "이면각 회전" 슬라이더가 활성화된다. 슬라이더를 움직이면 그 결합을 기준으로 구조가 실시간으로 회전한다. 고리에 속한 결합은 회전할 수 없다(비활성 표시).
- **이면각 스캔:** 원자 4개 선택 후 "이면각 스캔". 스텝 각도(5/10/15/30°)와 완화 스캔(각 각도에서 나머지 구조를 재최적화, 느리지만 더 정확) 여부를 직접 고른다.
- **그리드:** 헤더의 "그리드" 체크박스로 배경 3D 참조 격자를 켜고 끈다.
- **안정도 HUD:** 뷰어 좌상단에 0~100 점수와 문제 원자 칩이 뜬다. `▲`는 경고(VSEPR 편차·초원자가), `✕`(깜빡임)는 심각한 편차. 점수·색·모양으로 삼중 확인 가능.

## 학습 모드 vs 연구 모드

- **학습 모드:** 클릭으로 분자를 조립한다. 원소 선택기가 보이고, 원자를 붙일 때마다 자동으로 UFF 최적화가 돌아 바로 자리를 잡는다. VSEPR 형상을 완성하면 소리와 토스트로 알려준다.
- **연구 모드:** 클릭은 측정(거리·각도·이면각)용이다. 항별 에너지 분해, 최적화 리플레이 슬라이더 등 분석 패널이 추가로 보인다. 원자 부착은 하지 않으므로 기존 구조를 건드리지 않고 관찰·측정·스캔만 하고 싶을 때 쓴다.

## 테스트

```bash
node --test
```

`test/validation.test.js`가 문헌값(정사면체 109.47°, 에탄 회전장벽, 의자<보트)을 검증한다.
이 테스트가 깨지면 물리 결과를 신뢰하지 말 것.

## 물리 모델과 한계

- **역장:** UFF (Rappé et al., *JACS* **1992**, 114, 10024). 결합 신축 · 결합각 · 비틀림 · 반데르발스 4개 항.
- **포함하지 않는 것:** 정전기(부분전하) 항, 용매 효과, 전자 상관, 여기 상태. 전부 진공 기준.
- **신뢰 구간:** 2주기 유기 분자의 배좌 비교와 상대 에너지 경향은 정성적으로 유효하다.
  초원자가(PCl₅ 등)와 전이금속은 UFF가 축/적도 위치를 구분하지 못하므로 **정량 해석 불가**.
- **양자계산 대체가 아니다.** 반응 에너지, pKa, 전이상태에는 사용할 수 없다.

## 배포

GitHub Pages. **빌드 단계 없음** — 저장소 루트를 그대로 서빙한다.

1. GitHub → Settings → Pages
2. Source: `Deploy from a branch`
3. Branch: `main`, 폴더 `/ (root)` → Save
4. 1~2분 뒤 `https://<owner>.github.io/mol-craft/` 에서 열린다

CI(`.github/workflows/test.yml`)는 push/PR마다 `node --test`를 돌린다.
물리 검증 스위트가 빨간불이면 배포된 수치를 믿지 말 것.

## 저장과 공유

- **자동 저장:** `localStorage`(키 `molcraft:last`). 새로고침해도 마지막 구조가 복원된다.
- **링크 공유:** URL 해시(`#s=...`)에 구조를 담는다. 서버를 거치지 않으므로 영구히 유효하다.
  진입 시 우선순위는 URL 해시 > localStorage > 기본 프리셋이다.
- **단축 링크 / 공개 갤러리 (선택):** Supabase에 익명으로 저장한다. `src/config.js`가 비어 있으면
  이 기능만 꺼지고 나머지는 전부 동작한다. 무료 티어 프로젝트는 비활동 시 일시정지되므로
  **단축 링크는 영구 보관을 보장하지 않는다.** 영구 링크가 필요하면 해시 링크(`#s=`)를 쓸 것.
