# 분자 카탈로그 데이터 품질 기준

Mol-Craft 카탈로그는 **구조가 명확한 이산 화학물질 300종**을 대상으로 한다. 카탈로그는 검색·비교·2D 구조 렌더링을 일관되게 제공하는 것을 우선하므로, 조성비·평균 분자량·제조 등급에 따라 값이 달라지는 고분자 그 자체는 넣지 않는다. 대신 고분자 카테고리에는 구조식과 분자량이 명확한 단량체·전구체를 포함한다.

| 검증 항목 | 기준 | 허용되는 공백 |
|---|---|---|
| 식별 | `slug`, PubChem CID, 영문 명칭, 출처 URL이 있어야 한다. | CAS 번호는 PubChem 구조화 동의어에 없는 경우 비워 둘 수 있다. |
| 구조 | 분자식, 분자량, connectivity SMILES가 있어야 한다. | 이성질체 SMILES는 공급되지 않을 수 있다. |
| 분류 | 무기·유기·용매·생화학·약물·고분자 전구체 중 하나여야 한다. | 허용하지 않는다. |
| 물성 | XlogP, 수소결합 수, 극성 표면적과 실험 물성 주석을 가능한 범위에서 수집한다. | 실험 끓는점·녹는점·밀도·용해도는 PubChem 주석 부재 시 `null`을 유지한다. |
| 출처 | 모든 레코드는 PubChem CID 페이지로 역추적할 수 있어야 한다. | 허용하지 않는다. |

시드 생성·보완 과정은 우선 PubChem PUG-REST의 계산 속성 결과를 사용하고, 실험 물성은 PUG-View의 구조화 주석에 실제 값이 있을 때만 기록한다. 검색 불가 또는 필수 구조 필드가 없는 후보는 구조가 명확한 대체 이산 분자로 바꾸며, 임의 수치나 사용자 생성 리뷰를 추가하지 않는다. 최종 적재 전에는 레코드 수와 필수 필드 완결성을 검사한다. 현재 Supabase 검증 결과는 `total_count = 300`, `complete_count = 300`이다.

## 출처

1. [PubChem PUG-REST Tutorial](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest-tutorial) — 화합물 식별자와 계산 속성 조회.
2. [PubChem PUG-View](https://pubchem.ncbi.nlm.nih.gov/docs/pug-view) — 화학·물리적 주석 조회.
