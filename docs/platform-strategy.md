# Mol-Craft 교재 기반 상용 학습 플랫폼 전략

> **핵심 제안:** Mol-Craft는 “3D 분자 뷰어”가 아니라, 학생이 구조를 조작하고 예측·설명·검증하며 오개념을 수정하는 **유기화학 개념 숙달 플랫폼**으로 정의되어야 한다. 판매 가능한 제품의 단위는 분자 하나가 아니라, 측정 가능한 학습 성과를 내는 **교재 정렬형 실험 레슨**이다.

## 1. 출발점과 제품 포지셔닝

`Organic Chemistry: A Short Course, 13e` 지식베이스는 결합·기하(1–2장), π 결합·방향족성(3–4장), 입체화학(5장), 작용기별 반응(6–11장), 분광학(12장), 헤테로고리·생체분자(13–18장)로 개념이 누적되는 구조를 가진다. 현재 Mol-Craft는 구조 조립, VSEPR, 배좌, 일부 입체화학, 규칙 기반 IR/NMR, 형식전하, 정성 전기적 단서, 펩타이드·핵산 학습 노트라는 강한 기반을 이미 갖고 있다.

그러나 상용 플랫폼의 차별점은 모델을 “보여 주는 것”이 아니라 **학생의 생각을 드러내고 피드백을 주는 것**이다. 유기화학에서 입체화학 성취는 정신 회전과 3D 구조 시각화 능력의 영향을 받으며, 연습과 3D 모델 사용이 이를 보완할 수 있다는 연구 결과가 있다.[^spatial] 따라서 3D 캔버스는 핵심 자산이지만, 레슨·예측·진단·복습 체계가 없으면 판매 가능한 학습 경험으로 완성되지 않는다.

| 현재 강점 | 상용화 시 재정의할 가치 |
|---|---|
| 직접 조작 가능한 3D 분자 | 학생이 “왜 그런가”를 설명하도록 유도하는 관찰 실험 |
| UFF 기반 배좌·기하 비교 | 같은 연결성 내부의 정성 비교에 한정된 안전한 탐구 도구 |
| 형식전하·부분전하 시각 단서 | 전자 장부, 공명, 산·염기 추론의 단계형 훈련 |
| 교재 기반 학습 노트 | 장·절·학습목표·평가 문항에 연결된 마이크로레슨 |
| 카탈로그와 프리셋 | 레슨의 출발 구조와 학생 탐구 과제의 재료 |

## 2. 첫 시장과 제품 원칙

초기에는 모든 화학 학습자를 동시에 겨냥하지 말고 **대학 일반유기화학 입문 수강생과 해당 강좌의 교수자**를 첫 고객으로 삼는다. 고등학생 확장은 용어 수준, 교육과정, 미성년자 데이터 처리, 결제 방식이 달라 별도 제품 결정이 필요하다. 첫 유료 가치 제안은 “문제은행”이 아니라 다음과 같이 좁혀야 한다.

> **학생:** 공간적·시각적 유기화학 개념을 스스로 조작하고, 즉시 설명 가능한 피드백을 받아 시험 문제로 전이한다.  
> **교수자:** 교재 절 단위의 검증된 인터랙티브 과제와 개념별 오개념 데이터를 LMS 안에서 배포·채점한다.

이 선택은 단순 구독보다 기관 도입 가능성을 만든다. LTI 1.3은 교육기관 LMS와 도구를 안전하게 연결하고, 과제·성적 전송과 역할 정보를 다룰 수 있도록 설계되어 있다.[^lti] 따라서 초기 B2C 웹 경험을 유지하되, 제품 설계는 처음부터 “강좌·분반·과제·성취도” 객체를 갖춰야 한다.

## 3. 교재를 판매 가능한 학습 경험으로 바꾸는 레슨 엔진

### 3.1 모든 레슨에 필요한 6단계 학습 루프

각 레슨은 8–15분 분량으로 제한하고, 아래의 닫힌 루프를 반복해야 한다. 단순 읽기나 자유 조작만으로는 정답·오개념·성장을 판별할 수 없다.

| 단계 | 학생 행동 | 플랫폼이 기록할 증거 | 예시 |
|---|---|---|---|
| 1. 사전 예측 | 결과를 보기 전에 선택·스케치·서술 | 최초 답, 확신도, 응답 시간 | “부탄의 anti와 gauche 중 어느 쪽이 안정한가?” |
| 2. 조작 관찰 | 분자를 회전·결합·전하·이면각 조절 | 조작 경로, 관찰한 상태 | 이면각 스캔에서 두 최소점 찾기 |
| 3. 근거 연결 | 구조·전하·입체장애를 근거로 설명 | 짧은 설명, 선택 근거 | “vdW 반발이 어느 두 치환기에서 커지는가?” |
| 4. 즉시 피드백 | 규칙·모델 한계가 있는 피드백 수신 | 오개념 코드, 재시도 | “같은 위상에서만 UFF 상대 비교 가능” |
| 5. 전이 문제 | 표현을 바꾼 새 분자에 적용 | 독립 문항 정답률 | 치환 부탄의 배좌 비교 |
| 6. 회상 복습 | 며칠 뒤 짧은 혼합 퀴즈 | 숙달도, 망각 신호 | R/S·전하·분광학 혼합 회상 |

### 3.2 “학습목표-활동-평가” 정렬 규격

모든 콘텐츠는 교재 원문을 재서술하는 대신 독립적으로 작성하고, 아래 필드를 가진 콘텐츠 스키마로 관리한다. 그래야 교과서 판본, 교수자 커리큘럼, 한국어·영어 버전이 바뀌어도 재사용할 수 있다.

| 필드 | 요구사항 |
|---|---|
| `concept_id` | 예: `ch05.cip-ez`, `ch10.carboxylate-resonance`처럼 안정적 식별자 |
| 학습목표 | 관찰 가능한 동사와 성공 기준을 포함한 한 문장 |
| 선수 개념 | 결합차수, 형식전하, CIP 등 필요한 개념 그래프 |
| 표현물 | 2D 구조식, 3D 모델, 조작 상태, 설명 카드의 역할 분리 |
| 모델 등급 | 결정론적 규칙 / 규칙 기반 추정 / 실험값 인용 / 계산 모델 중 하나 |
| 오개념 | 예상되는 잘못된 추론, 맞춤 피드백, 재시도 활동 |
| 평가 | 진단·형성·전이·회상 문항과 채점 기준 |
| 검토 이력 | 화학 검토자, 교육 검토자, 버전, 근거 출처 |

### 3.3 우선 개발해야 할 레슨 묶음

전 장을 한 번에 만들지 않는다. 첫 유료 MVP는 교재의 핵심 병목이면서 Mol-Craft의 조작 자산이 강한 네 묶음으로 구성한다.

| 우선순위 | 교재 축 | 최초 판매용 레슨 패키지 | 성공 판정 |
|---|---|---|---|
| P0 | 1–2장: 구조·배좌 | 형식전하/공명 장부, VSEPR, 에탄·부탄 배좌, 고리 axial/equatorial | 예측 후 전이 문항 정확도 상승 |
| P1 | 3–5장: π·방향족·입체 | 회전 제한, 방향족성, CIP R/S·E/Z, 거울상과 메조 | 2D↔3D 변환과 구성 판정의 오개념 감소 |
| P2 | 9–12장: 카보닐·분광 | sp²→sp³ 변화, 공명·카복실레이트, IR/NMR 구조 역추론 | 스펙트럼 근거를 구조 가설과 연결 |
| P3 | 13·17·18장: 생체유기 | 피리딘/피롤, 아미노산 쯔비터이온, 펩타이드 φ/ψ, 핵산 5′→3′ | 모델 한계를 포함해 올바른 설명 작성 |

## 4. 과학적 정직성은 판매 기능이다

Mol-Craft가 신뢰를 얻으려면 “계산됨”과 “알려진 사실”을 구분해야 한다. UFF는 같은 연결성을 가진 배좌의 정성 비교에는 유용할 수 있지만, pKa, 반응 경로, 전이상태, 수율, 서로 다른 위상의 총에너지 비교를 예측하는 도구로 제시하면 안 된다. 이 원칙은 사용자의 학습 신뢰뿐 아니라 기관 판매 시 교수자의 채택 판단을 좌우한다.

| 표시 등급 | 사용 가능한 주장 | UI 규칙 |
|---|---|---|
| **정답 규칙** | 원자가, 형식전하 장부, DoU, CIP의 지원 범위, 구조식 패턴 | “규칙 기반 판정” 배지와 판정 근거를 표시 |
| **정성 모델** | 부분전하 단서, 비결합 접촉, 방향족 전자 기여 | “정성 단서” 배지와 제외 요소(용매·전자 비편재화)를 병기 |
| **제한적 계산** | 같은 분자의 배좌·이면각 스캔·기하 완화 | “UFF 상대 비교” 배지, 비교 가능 조건과 불확실성 표시 |
| **외부 사실** | 실험 IR 범위, 문헌 장벽, pKa, 생체분자 결합 수 | 출처·조건·단위·판본을 함께 제시 |
| **미지원 영역** | 생성물 예측, 반응속도, 수율, 의약적 의미 | 답을 생성하지 않고 학습 경계 카드로 전환 |

특히 **AMP 교육용 골격**처럼 원자 연결과 전하를 읽기 위한 구조는 UFF 에너지·충돌·DoU·분광학·입체화학의 수치 평가에서 명시적으로 제외해야 한다. 이처럼 모델의 적용 범위를 화면에 보여 주는 동작은 기능 부족이 아니라 과학 교육 제품의 품질 관리다.

## 5. 학생용·교수자용 제품 표면

### 학생 경험

학생은 “캔버스”가 아니라 강좌 홈에서 시작한다. 진단 결과로 추천되는 개념 경로, 오늘의 10분 레슨, 보류된 오개념, 누적 노트를 보며 학습한다. 자유 조립실은 항상 열어 두되, 레슨 안에서는 필요한 조작만 단계적으로 노출한다.

필수 기능은 개념 진단, 레슨 플레이어, 힌트 단계, 풀이 근거 입력, 개인 오개념 카드, 간격 반복 복습, 과제 제출 기록, 접근 가능한 2D 대체 표현이다. AI가 들어가더라도 정답을 대신 생성하는 챗봇보다 **학생의 설명을 루브릭에 따라 되묻고, 근거 없는 단정을 차단하는 코치**가 우선이다.

### 교수자 경험

교수자에게는 “멋진 3D”보다 준비 시간 단축과 수업 근거가 가치다. 장·개념·난이도·모델 등급으로 과제를 골라 배포하고, 완료율·첫 시도 정답률·재시도 뒤 개선·오개념 분포를 분반 수준에서 확인할 수 있어야 한다. 자유형 분자 조립 과제는 자동 판정 가능한 구조 규칙과 사람이 검토할 설명 루브릭을 분리한다.

| 학생 기능 | 교수자 기능 | 기관 도입 가치 |
|---|---|---|
| 개인 진단과 추천 경로 | 주차별 과제 템플릿 | 기존 강의 흐름을 바꾸지 않고 도입 가능 |
| 조작·예측·설명 레슨 | 개념별 성취·오개념 대시보드 | 시험 전 개입 지점 확인 |
| 복습 큐와 학습 노트 | 루브릭·재시도·마감 정책 | 형성평가의 일관성 |
| 접근 가능한 대체 표현 | LTI 배포·성적 반환 | LMS와의 낮은 마찰 연동 |

## 6. 상용 플랫폼 운영 기반

현재 정적 애플리케이션은 개념 증명에는 적합하지만, 유료 제품에는 계정·권한·콘텐츠·학습기록을 분리한 서버 기반 도메인 모델이 필요하다.

| 영역 | 판매 전 필수 | 후속 고도화 |
|---|---|---|
| 계정·권한 | 학생/교수자/조교/관리자 역할, 기관·강좌 분리, 최소 권한 | SSO, SCIM, 조직별 정책 |
| 학습 데이터 | 레슨 시도, 답안, 숙달도, 동의·삭제 요청, 감사 로그 | 개념 지식추적·실험 분석 |
| 콘텐츠 | 버전된 레슨·문항·루브릭·출처·검토 워크플로 | 교수자 저작 도구와 승인 큐 |
| 신뢰성 | 백업·복구 테스트, 상태 모니터링, 오류 추적, 성능 기준 | 다지역·대규모 시험 피크 대응 |
| 결제·권한 | 명확한 체험/유료 범위, 영수증·해지·환불 정책, 권한 즉시 반영 | 기관 견적·좌석 라이선스·프로비저닝 |
| 교육 연동 | CSV 내보내기와 LMS 링크 | LTI 1.3, Deep Linking, AGS 성적 반환 |

LTI 1.3/LTI Advantage는 추가 로그인 없이 기관 학습 환경에서 도구를 열고, 역할·과제·성적 흐름을 연결할 수 있게 한다.[^lti] 다만 첫 B2C 출시에서 즉시 구현할 필요는 없으며, 강좌 파일럿 계약 이전의 명확한 게이트로 두는 편이 효율적이다.

| 개인정보 | 최소 수집 항목, 목적, 보관 기간, 삭제·열람 절차, 처리위탁 | 학습 로그는 성적·학습행동 정보가 될 수 있으므로 광고용 추적과 분리하고 최소화 |
| 미성년자 | 고등학생 판매 여부, 보호자 동의, 학교 제공 계정의 경계 | 대학생 B2C와 미성년자 대상 제품을 동일한 동의 흐름으로 취급하지 않음 |
| 전자상거래 | 가격, 자동갱신, 무료체험, 환불·해지, 영수증·고지 | 결제 화면과 약관에서 숨기지 않고 구매 전 명시 |
| 접근성 | 키보드, 포커스, 터치 대안, 색 이외의 표현, 텍스트 대체, 자막 | WCAG 2.2 AA를 출시 기준으로 삼고 자동·수동 검증을 함께 수행 |
| 보안 | 암호화, 비밀 관리, 권한 점검, 취약점 대응, 백업·복구 | 학습 데이터와 결제 정보를 별도 경계로 보호 |

WCAG 2.2는 다양한 장애와 모바일 환경을 포함하는 웹 접근성 권고이며, 준수 기준을 테스트 가능한 성공 기준으로 제시한다.[^wcag] Mol-Craft에는 특히 드래그 대안, 명확한 포커스, 색만으로 전하·선택 상태를 전달하지 않는 방식, 3D 캔버스의 구조적 텍스트 요약이 중요하다. 학생 데이터 보호는 교육 기록의 접근·공유를 통제하는 제도와도 연결되므로, 기관 파일럿 전 데이터 처리 부속서와 삭제·반환 절차를 준비해야 한다.[^privacy]

## 8. 단계별 로드맵과 출시 판정

### 단계 A — 학습 코어 완성

목표는 “3D 조립 앱”에서 “평가 가능한 레슨”으로 전환하는 것이다. P0~P2 레슨 24~36개, 진단 1개, 전이 문항·오개념 피드백·학습 이력을 구현한다. P4의 전하 모델을 기반으로 공명 비교, 카보양이온/카바니온, 카복실레이트, 쯔비터이온 레슨을 만든다. 이 단계의 완료 기준은 파일럿 학생이 레슨 전후의 독립 전이 문항에서 측정 가능한 향상을 보이고, 교수자가 과제 준비 없이 한 주차 분량을 배포할 수 있는 상태다.

### 단계 B — 유료 개인 학습 MVP

목표는 유기화학 수강생이 스스로 결제할 만한 반복 사용성이다. 계정, 진단 기반 경로, 진도·복습, 콘텐츠 버전, 결제 권한, 지원 채널, 개인정보·환불 고지를 갖춘다. 가격은 기능 수가 아니라 “시험 전 특정 개념군을 확실히 이해시키는 레슨 번들”에 연결한다. 이 단계에서는 AI 답변보다 정답 규칙과 검토된 피드백의 신뢰도를 우선한다.

### 단계 C — 교수자 파일럿과 기관 제품

목표는 한두 개 분반에서 실제 과제와 성취도 데이터를 검증하는 것이다. 교수자 과제 빌더, 분반 대시보드, LMS 링크, 성적 내보내기를 제공한다. 파일럿으로 학생 완료율, 전이 문항 향상, 교수자 준비 시간, 재도입 의향을 수집한다. 이 지표가 확보되면 LTI 1.3/AGS, 기관 계약, 조교 역할, 좌석 관리로 확장한다.

### 단계 D — 개념 그래프 기반 적응형 플랫폼

목표는 18개 장을 모두 채우는 것이 아니라, 선수 개념 실패를 정확히 찾아 다음 활동을 바꾸는 것이다. 이후 반응 메커니즘 화살표, 탄수화물 아노머, 20종 아미노산, 분광 통합 추론, 교수자 콘텐츠 저작을 추가한다. 양자화학·반응 예측·대규모 단백질 모델링은 별도 검증 체계가 없으면 범위에 넣지 않는다.

## 9. 제품 KPI와 중단 기준

유료 전환보다 먼저 학습 효용을 검증한다. 단순 체류 시간은 조작이 재미있는지 정도만 보여 주며, 이해를 보장하지 않는다.

| 범주 | 핵심 지표 | 출시 판단 예시 |
|---|---|---|
| 학습 효용 | 사전 예측 대비 전이 문항 향상, 7일 뒤 회상 정확도 | 핵심 레슨에서 개선이 없으면 인터랙션을 재설계 |
| 오개념 | 오개념별 첫 시도·재시도·잔존 비율 | 특정 오개념이 계속되면 피드백과 표현을 수정 |
| 사용성 | 레슨 완료율, 도움말 진입률, 3D 조작 실패율 | 조작 UI가 학습보다 큰 장벽이면 단순화 |
| 교수자 가치 | 과제 생성 시간, 배포율, 재사용률 | 대시보드가 행동 변화로 이어지지 않으면 제거·개선 |
| 신뢰성 | 오류율, 데이터 복구 성공률, 접근성 결함 해결 시간 | 고위험 결함이 있으면 기관 판매 보류 |
| 사업성 | 무료→유료 전환, 월 유지율, 강좌 재계약·재도입 의향 | 학습 효용 지표를 만족한 코호트에서만 확장 |

## 10. 당장 하지 말아야 할 것

첫째, 교재의 문장·도판·문제를 허가 없이 서비스에 대량 재수록하지 않는다. 둘째, UFF 출력이나 정성 부분전하를 pKa·수율·생물활성·반응 생성물의 예측값처럼 판매하지 않는다. 셋째, AI가 자유 서술로 화학적 사실을 단정하게 두지 않는다. 넷째, 학생 데이터를 광고 타기팅이나 불투명한 프로파일링에 쓰지 않는다. 다섯째, 18개 장을 얕게 덮기 위해 검토되지 않은 콘텐츠를 급히 늘리지 않는다.
