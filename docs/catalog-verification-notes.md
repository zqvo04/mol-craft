# 카탈로그 UI 검증 메모

기존 조립·UFF 분석 화면은 로컬 정적 서버에서 정상 표시되었고, 헤더에 **분자 카탈로그** 진입 버튼과 비교 선택 수 배지가 추가된 것을 확인했다. 기존 도구 모음, 3D 뷰어, 에너지 패널과 공개 갤러리는 이 진입점 추가 후에도 화면에 함께 표시되었다.

카탈로그 대화상자 내부의 검색·카드·상세·비교 흐름은 다음 검증 단계에서 직접 열어 확인한다. 현재 검증 환경은 기존 GitHub 저장소를 `/home/ubuntu/mol-craft-existing`에 복제해 정적 서버로 실행한 사본이다.

추가 검증에서 카탈로그는 기존 Supabase 테이블에서 **300종**을 정상적으로 읽었고, `Aspirin` 실시간 검색 결과는 1개로 즉시 축소되었다. PubChem의 SVG 구조식 경로는 지원되지 않아 브라우저에서 이미지 로드에 실패했으므로, 지원되는 2D PNG 렌더링 경로로 전환했다.

PNG 경로 전환 후 카탈로그 카드와 상세 패널에서 2D 구조식이 정상 렌더링되었다. 검증에 사용한 구조식 API 패턴은 `https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/cid/{CID}/PNG?image_size=large`이며, 카탈로그는 기존 Supabase 프로젝트 `erqvcpdpvrecjdfmtsue`의 `molecule_catalog` 테이블에서 300종을 읽는다.

페이지네이션 보완 후 전체 결과는 24개 카드 단위의 **13쪽**으로 표시되었다. 첫 페이지에서 `1-Butanol`이 기본 상세 패널에 동기화되어 분자식·CAS·SMILES·구조식이 함께 표시되는 것을 확인했다. 검색·필터·정렬 변경 시 상세 선택은 현재 결과 집합의 첫 번째 레코드로 자동 동기화되도록 구현했다.

교육형 UI/UX 개선의 브라우저 확인에서는 편집 도구가 `보기·선택·지우개·결합·차수`로 정리되고, 원소 팔레트 옆 `구조 단위` 버튼에서 벤젠·사이클로헥산·사이클로펜탄·피리딘·푸란·카보닐·하이드록실·알켄을 그룹별로 선택할 수 있음을 확인했다. 구조 단위 라이브러리는 유리 표면·둥근 모서리·짧은 전환을 기존 작업 공간과 공유하며, 우측 인스펙터에는 `분석`과 `학습 노트` 탭이 표시된다.

학습 노트 탭은 현재 구조의 원자·결합 수와 혼성화, 기능기 힌트, 1–2/1–3 결합 이웃을 제외한 근접 비결합 접촉, 비틀림 학습 안내, UFF 해석 한계를 제공한다. 메탄의 수소 원자처럼 공유 중심을 통한 1–3 쌍은 입체장애로 표시하지 않도록 보정했다. 카탈로그는 전체 작업 공간을 대체하지 않는 우측 liquid-glass 슬라이드오버로 표시되며, 배경 작업 공간의 맥락·카드 목록·상세 인스펙터가 함께 보이는 것을 확인했다.

구조 단위 라이브러리를 다시 연 뒤에는 기존 도구 상태·원소 팔레트·분석 인스펙터가 유지되었고, 라이브러리 내부의 각 템플릿 버튼에는 삽입 대상과 기능 설명이 함께 노출되었다.

라이브러리의 공개 상태와 각 구조 단위 버튼의 키보드 초점 가능한 DOM 상태를 다시 확인했다. 선택 후 고스트 배치·회전은 모델 단위 테스트와 후속 상호작용 검증 대상으로 분리해 관리한다.

구조 단위 라이브러리의 외부 영역을 클릭해 닫는 동작과 브라우저 콘솔을 점검했으며, 해당 흐름에서 런타임 오류는 보고되지 않았다.

브라우저 자동화 환경에서는 라이브러리 카드 선택 직후 요소 인덱스가 갱신되어 클릭 대상이 변경되는 현상을 확인했다. 구조 단위 모델의 첨부·원자가·회전 경로는 자동 회귀 테스트로 검증하며, 실제 카드 이벤트는 DOM 이벤트 경로를 별도 확인한다.

375×812 모바일 뷰포트와 `prefers-reduced-motion: reduce`를 강제한 동일 뷰포트에서 화면을 각각 렌더링했다. 모바일에서는 헤더·편집 도구·원소 팔레트·구조 단위 진입점이 한 열로 재배치되어 가로 오버플로 없이 표시됐고, 감소된 모션 상태에서도 콘텐츠 계층과 버튼 가독성이 유지됐다. 감소된 모션 CSS 규칙의 적용은 UI 계약 테스트로도 확인했다.

키보드 전용 흐름에서는 `구조 단위` 버튼에 포커스를 둔 뒤 Enter로 라이브러리를 열 수 있었다. 벤젠 템플릿을 선택한 상태에서는 상단 버튼의 활성 상태, 도구 안내의 `구조 단위 삽입` 문구, 현재 단위와 회전값, 삽입 안내 토스트가 함께 갱신되는 것을 확인했다.

실제 브라우저 DOM 상호작용으로 카보닐 구조 단위 선택→삽입 모드 전환, 학습 탭 전환, 카탈로그 열기·닫기를 연속 실행했다. 구조 단위 활성 상태와 도구 안내의 현재 단위, 학습·분석 패널의 `hidden` 상태, 카탈로그의 `open` 상태가 모두 기대값으로 전환됨을 확인했다. 키보드 Enter로 라이브러리를 다시 열었을 때에도 현재 선택 단위와 삽입 안내가 유지됐다.

최신 화면에서는 분석 패널에 비틀림 스캔 버튼과 상대 에너지 표본 안내가 추가됐으며, 학습 노트에는 메탄의 `C0 · sp³ · 정사면체`, 이상 결합각 `109.47°`, 결합각에 영향을 주는 고립전자쌍·입체장애·다중결합 해설 카드가 정상 표시됐다.

원격 디버깅 기반 통합 검증에서는 375×812 모바일과 `prefers-reduced-motion: reduce`를 에뮬레이션한 상태에서 구조 단위 라이브러리 열기·벤젠 선택·삽입 모드 전환·학습 탭 전환·카탈로그 열기를 자동 실행했다. 카탈로그는 실제 **300종**의 레코드와 1쪽 카드·상세 패널까지 로드된 상태로 캡처됐다. 별도 키보드 흐름에서는 Enter 키만으로 라이브러리 열기·첫 템플릿 선택·학습 탭 전환·카탈로그 열기와 닫기를 모두 통과했다.
