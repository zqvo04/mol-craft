# 카탈로그 UI 검증 메모

기존 조립·UFF 분석 화면은 로컬 정적 서버에서 정상 표시되었고, 헤더에 **분자 카탈로그** 진입 버튼과 비교 선택 수 배지가 추가된 것을 확인했다. 기존 도구 모음, 3D 뷰어, 에너지 패널과 공개 갤러리는 이 진입점 추가 후에도 화면에 함께 표시되었다.

카탈로그 대화상자 내부의 검색·카드·상세·비교 흐름은 다음 검증 단계에서 직접 열어 확인한다. 현재 검증 환경은 기존 GitHub 저장소를 `/home/ubuntu/mol-craft-existing`에 복제해 정적 서버로 실행한 사본이다.

추가 검증에서 카탈로그는 기존 Supabase 테이블에서 **300종**을 정상적으로 읽었고, `Aspirin` 실시간 검색 결과는 1개로 즉시 축소되었다. PubChem의 SVG 구조식 경로는 지원되지 않아 브라우저에서 이미지 로드에 실패했으므로, 지원되는 2D PNG 렌더링 경로로 전환했다.

PNG 경로 전환 후 카탈로그 카드와 상세 패널에서 2D 구조식이 정상 렌더링되었다. 검증에 사용한 구조식 API 패턴은 `https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/cid/{CID}/PNG?image_size=large`이며, 카탈로그는 기존 Supabase 프로젝트 `erqvcpdpvrecjdfmtsue`의 `molecule_catalog` 테이블에서 300종을 읽는다.

페이지네이션 보완 후 전체 결과는 24개 카드 단위의 **13쪽**으로 표시되었다. 첫 페이지에서 `1-Butanol`이 기본 상세 패널에 동기화되어 분자식·CAS·SMILES·구조식이 함께 표시되는 것을 확인했다. 검색·필터·정렬 변경 시 상세 선택은 현재 결과 집합의 첫 번째 레코드로 자동 동기화되도록 구현했다.
