# mol-craft 표현력 격차 종합

18개 장 노트의 `## ⚙ mol-craft 접점`을 코드 근거로 묶은 것. **개선 로드맵의 입력이지 로드맵 자체는 아니다** — 우선순위 결정은 별도 논의.

---

## 1. 구조적 제약 (여러 장을 동시에 막는 것)

### C-1. `charge` 필드 부재 — **최다 차단**
`mol.atoms[i]`에 형식전하 필드가 없다.
막히는 것: 형식전하(Ch1) · 카보양이온/카바니온(Ch3·8) · 알콕사이드/페녹사이드(Ch7) · 카복실레이트(Ch10) · 엔올레이트(Ch9) · 4급 암모늄/디아조늄(Ch11) · 아레늄 이온(Ch4) · **쯔비터이온(Ch17)** · 인산 음전하(Ch18).
- 부작용: `LONE_PAIRS`가 중성 기준 고정 상수(`snap.js:22`)라 이온에서는 **틀린 비공유쌍 자리를 그린다**.
- Ch17에서 특히 문제: 아미노산의 **실제 존재 형태(쯔비터이온)를 그릴 수 없고 존재하지 않는 중성형만 그린다** → 학습 도구로서 정직성 문제.

### C-2. 정전기(부분전하) 항 부재 — README 명시
막히는 것: 수소결합 전부(Ch7 알코올 · Ch10 카복실산 이량체 · **Ch14 나일론** · **Ch17 α-나선/β-병풍** · **Ch18 A–T/G–C 염기쌍**) · 분자 쌍극자(Ch1) · 극성 배좌 효과.
- Ch18에서 **A–T(2개) vs G–C(3개) 수소결합 차이를 에너지로 보여줄 수 없다** — 이 장의 핵심 정량 사실.
- UFF 원 논문에 QEq 전하 계산법이 포함돼 있어 **이론적 근거는 확보돼 있다**.

### C-3. 입체화학 판정 코드 전무
CIP 우선순위·입체중심 탐지·R/S·E/Z가 하나도 없다. 2D 쐐기/파선은 **3D z좌표 차이로만** 그려져(README 명시) 시점에 따라 뒤집힌다.
막히는 것: Ch5 전부 · Ch6 Walden 반전 서술 · Ch15 cis/trans 라벨 · Ch16 D/L·α/β 아노머 · Ch17 L/D 아미노산.
- **필요한 재료는 이미 있다**: `neighbors`/`bondOrderSum`(그래프), `geom.cross/dot/dihedralDeg`(부호 있는 기하).

### C-4. sp² 공액 인식 부재
`typeAtom()`이 **최대 결합 차수**로만 혼성을 정한다(`uff.js:30-32`) → 공명으로 sp²가 되어야 할 원자가 sp³로 남는다.
틀린 기하가 나오는 것: **아마이드 N(Ch10·17)** · 아닐린 N(Ch11) · 에스터 O · 엔아민 · 비고리 콘주게이션(Ch3 1,3-뷰타다이엔).
- **Ch17이 이것 없이는 성립하지 않는다** — 펩타이드 결합이 평면이 아니면 φ/ψ·라마찬드란·2차 구조가 전부 무의미.
- 해결 위치: `model.js`의 `aromatize()` 옆에 같은 방식의 국소 규칙("sp² 카보닐 탄소에 결합한 sp³ N/O → `N_R`/`O_R`").

### C-4b. `aromatize()`가 헤테로방향족을 전부 놓친다 — **실측 확인**
`model.js:167-181`의 조건이 **벤젠형 전용**이다: `모든 고리 원자의 이웃이 정확히 3개` + `모든 고리 원자가 이중결합 보유`.

| 분자 | aromatize 결과 | 실패 조건 |
|---|---|---|
| 벤젠 | ✓ `C_R` / 차수 1.5 | — |
| **피리딘** | ✗ `N_2` | N의 이웃이 2개 (H 없음) |
| **피롤** | ✗ `N_3` | N에 이중결합 없음 (π 공여자이므로 당연) |
| **푸란** | ✗ `O_3` | 위와 동일 |

→ **Ch13 전체와 Ch18의 핵심염기 5종이 방향족으로 인식되지 않는다.** `UFF_PARAMS`에 `N_R`(120°)·`O_R`(110°)은 **이미 있으므로 파라미터가 아니라 인식 규칙만의 문제.**
- **수정 방향**: 고리 원자별 π 기여 계수 — sp²C = 1 · 피리딘형 N(이웃 2, 이중결합 O) = 1 · **피롤형 N(이웃 3, 이중결합 X) = 2** · 푸란형 O/S(이웃 2, 이중결합 X) = 2 → 합이 4n+2면 승격. **Ch4의 휘켈 판정과 Ch13의 헤테로방향족 인식을 동시에 해결한다.**
- **⚠ 동반 수정 필요(실측 확인)**: 피롤 N을 `N_R` + 고리결합 1.5로 만들면 `bondOrderSum = 4 > MAX_VALENCE.N = 3` → `stability()`가 **`원자가 초과(4/3)` danger를 오탐**한다. 방향족 결합의 원자가 회계를 별도 처리해야 한다.
- 부수 효과: 방향족 N이 sp³로 남아 있어 **반전(평면성) 항이 적용되지 않는다** → 헤테로고리가 완전한 평면이 되지 않음(Ch18 염기 쌓임의 전제).

### C-5. `findRings()`가 정식 SSSR이 아님
`model.js:102` 주석과 README가 명시. 다리·융합 고리계에서 과대/중복 계산.
영향: **스테로이드(Ch15)** · **이당류/다당류(Ch16)** · **퓨린 융합 고리(Ch18)** — 생체분자 3개 장이 전부 취약 케이스.

### C-6. 규모 한계
`buildTerms()`의 vdW가 O(n²), `gradient()`가 항별 **수치 중심차분**(`uff.js:284` 주석: "수천 원자 규모로 키우려면 해석 미분으로 교체").
실용 상한 ≈ 100–150원자 → 올리고머(Ch14) · 다이/펜타펩타이드(Ch17) · 이당류(Ch16)까지. **단백질·이중나선은 원리적으로 불가.**

### C-7. 지원 원소 제한
`UFF_PARAMS`: H B C N O F Si P S Cl Br I 만.
막히는 것: **Mg/Li(그리냐르·유기리튬, Ch8)** · Ti/Al(치글러-나타, Ch14) · **Fe/Mg/Co(포르피린 중심 금속, Ch13)**.

## 3. 순수 그래프/기하 연산만으로 구현 가능한 것 (양자 계산 불필요)

정확도 위험이 낮고 **정답이 존재하는** 기능들. 학습 플랫폼화의 실질적 재료.

| 기능 | 필요한 것 | 여는 장 |
|---|---|---|
| **DoU(불포화도)** | 원소 개수 + `bondOrderSum` | Ch1·12 |
| **구조 이성질체 판별** | `formula()` 같음 + `topologyKey()` 다름 — **함수 둘 다 이미 존재** | Ch1 |
| **CIP 우선순위 → R/S·E/Z** | 그래프 BFS(다중결합 복제) + 삼중곱 부호 | **Ch5·6·15·16·17** |
| **거울상/부분입체/메조 판정** | 거울 반전 + 그래프 정합 | Ch5 |
| **axial/equatorial 라벨** | `findRings()` + 고리 평면 법선 각도 | **Ch2·6·15·16** |
| **π 전자 계수 → 휘켈 4n+2** | 고리 원자별 기여(sp²C=1, 피롤형N=2, 피리딘형N=1, 푸란O=2) | **Ch4·13** |
| **NMR 신호 개수·적분비** | 그래프 자기동형(Morgan 근사) | **Ch12** |
| **n+1 다중도(등가 조건 포함)** | 이웃 H 개수 + 등가 집합 | Ch12 |
| **작용기 검출 → 예상 IR 밴드** | 부분 그래프 매칭 | Ch12 |
| **헤미아세탈/아세탈·아노머 탄소 식별, 환원당 판정** | 패턴 매칭 | Ch16 |
| **φ/ψ 측정** | `model.measure()` — **이미 가능** | Ch17 |
| **퓨린/피리미딘 폭 측정** | 좌표 거리 | Ch18 |

## 4. UFF 정확도 주의 (수치를 화면에 그대로 내면 안 되는 것)

| 항목 | mol-craft | 문헌 | 근거 |
|---|---|---|---|
| 부탄 syn 장벽 | **6–14** kcal/mol | 4.5–6.1 | `validation.test.js:94` (주석에 "UFF 과대평가" 명시) |
| 부탄 anti-gauche | 0.5–3 | 0.9 | `validation.test.js:92` |
| gauche 이면각 | 55–90° | 65° | `validation.test.js:91` |
| 술폭사이드/포스핀옥사이드 | 정성 근사 | — | `uff.js:33-41`, UFF 원 논문에 중간 원자가 타입 부재 |
| 초원자가(PCl₅ 축/적도) | 구분 못 함 | — | README, `validation.test.js:67` |

**원칙 3가지**
1. **위상(topology)이 다른 두 분자의 UFF 총에너지를 비교하면 안 된다.** 케토 vs 엔올(Ch9), 유도체 반응성(Ch10), 토토머(Ch18) — 전부 비교 불가. 같은 위상의 **배좌** 비교만 유효.
   - 단 **부분입체 이성질체는 비교 가능**(위상 동일, 입체만 다름) → **Ch16 α/β 아노머는 정당한 UFF 사용**.
2. **거울상은 UFF 에너지가 정확히 같다** — 모든 항이 거리·각·|이면각|의 함수. 최적화로 R/S를 구분하려는 시도는 원리적으로 불가(Ch5).
3. **pKa·반응 에너지·전이상태는 범위 밖**(README 명시). 시도 자체를 UI에서 막아야 한다.

## 6. 프리셋/템플릿 확충 후보
현재 `PRESETS` 10종(methane, water, ammonia, ethylene, ethane, butane, sf6, pcl5, cyclohexane chair/boat), `RING_TEMPLATES` 2종(benzene, cyclohexane).
추가 가치가 큰 것: **에폭사이드**(Ch8) · **피리딘·피롤·이미다졸·피리미딘**(Ch13·18) · **핵염기 5종 + 리보스/디옥시리보스**(Ch18) · **아미노산 20종**(Ch17) · **글루코스 α/β 피라노스**(Ch16) · **스테아르산/올레산**(Ch15) · **아마이드 최소 예(다이펩타이드)**(Ch10·17).
