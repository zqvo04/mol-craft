## 뿌리 개념 4개 (책 전체가 이 위에 서 있다)

### A. 혼성 / VSEPR 기하
`Ch1 sp³ 109.47°` → `Ch3 sp² 120° · sp 180°` → `Ch4 방향족 평면 sp²` → `Ch13 헤테로방향족`
- 하위 의존: `Ch2 고리 스트레인`(이상각 이탈), `Ch9 카보닐 sp²→sp³ 전환`, `Ch17 아마이드 평면`

### B. 공명 / 전자 비편재화
`Ch1 공명 기여 구조` →
- → `Ch3 알릴 양이온` → `Ch6 Sₙ1 안정화`
- → `Ch4 방향족성 36 kcal/mol` → `Ch4 EAS 지향성` → `Ch11 디아조 짝지음`
- → `Ch7 페녹사이드(산도↑)` ∥ `Ch11 아닐린(염기도↓)` — **같은 원인, 반대 방향**
- → `Ch10 카복실레이트(산도)` · `Ch10 아마이드(평면·비염기성)` → **`Ch17 φ/ψ 두 자유도` → `Ch17 라마찬드란·2차 구조`**
- → `Ch9 엔올레이트` → `Ch9 알돌` · `Ch10 클라이젠`
- → `Ch13 피롤형 N(비공유쌍 공여)` vs `피리딘형 N(공여 안 함)` → `Ch18 핵염기`

### C. 입체 반발 / 형태
`Ch2 비틀림·입체 스트레인` →
- → `Ch2 의자 형태 · axial/equatorial · A-value` → **`Ch16 β-글루코스 전-equatorial`**
- → `Ch6 Sₙ2 뒷면 차폐(3° 불가)` · `Ch6 Hofmann(부피 큰 염기)`
- → `Ch14 입체 규칙성 → 결정성` · `Ch15 cis 꺾임 → 융점` · `Ch17 라마찬드란 허용 영역`

### D. 전기음성도 / 극성
`Ch1 δ⁺/δ⁻` → `Ch3 친전자체/친핵체` → **모든 극성 메커니즘(Ch6·8·9·10)**
- → `Ch7 유도효과(거리 감쇠)` → `Ch10 치환기 pKa 사다리`
- → `Ch12 IR C=O 위치` · `Ch12 NMR 화학적 이동`

## 주요 단방향 의존(선행 없으면 이해 불가)

```
Ch5 CIP 규칙 ──┬─→ Ch5 R/S · E/Z
               ├─→ Ch6 Walden 반전 / 라세미화 서술
               ├─→ Ch16 D/L · α/β 아노머
               └─→ Ch17 L-아미노산(단, Cys만 R)

Ch9 헤미아세탈/아세탈 ──┬─→ Ch16 당의 고리형 구조 · 글리코사이드
                        └─→ Ch18 N-글리코사이드(뉴클레오사이드)

Ch10 아마이드 공명 ──┬─→ Ch14 나일론(사슬 간 수소결합)
                     └─→ Ch17 펩타이드 평면성 → 2차 구조

Ch6 이탈기 원리 ──┬─→ Ch7 알코올 활성화(양성자화·토실화·SOCl₂)
                  ├─→ Ch8 에폭사이드 열림 · 윌리엄슨(1° 전용)
                  └─→ Ch11 호프만 제거(–NR₃⁺)

Ch4 휘켈 · EAS ──┬─→ Ch13 헤테로방향족 EAS 위치선택성
                 └─→ Ch11 아닐린 활성화 · 디아조 짝지음

Ch2 라디칼 연쇄 ──→ Ch14 사슬 성장 중합

Ch12 (전 장의 산물) ──→ Ch13–18 화합물 동정의 전제
```

## 교재 내부의 끊긴 연결(원문 요약본 기준)
아래는 **원문에서 전제가 공급되지 않은 채 사용되는 곳**. 학습 자료로 재구성할 때 반드시 메워야 한다.
1. `Ch13`이 이미다졸·피리미딘·퓨린을 다루지 않는데 **`Ch18`이 퓨린/피리미딘을 전제**한다.
2. `Ch10`이 아마이드 회전 제약을 말하지만 **`Ch17`의 φ/ψ·2차 구조로 연결되지 않는다**.
3. `Ch2`가 axial/equatorial을 정의만 하고 **`Ch16`의 β-글루코스 전-equatorial로 이어지지 않는다**.
4. `Ch5`의 CIP가 **`Ch16` D/L·아노머, `Ch17` L/D 아미노산**에서 다시 쓰이는데 규칙이 불완전하게 서술돼 있다.
5. `Ch9`의 케토-엔올이 **`Ch18` 염기 호변이성 → 돌연변이**로 이어지지 않는다.
