# Ch11. Amines and Related Nitrogen Compounds

## Presupposes
Ch1: 비공유쌍, 형식전하, 공명. Ch4: EAS, 활성화기·지향성. Ch5: 카이랄성, 분할. Ch6: Sₙ2, E2. Ch10: 아마이드, 유도/공명 효과.

## 개념
- **아민 분류**: NH₃의 H를 R로 치환한 개수 — 1°(RNH₂), 2°(R₂NH), 3°(R₃N), **4급 암모늄 염 R₄N⁺**(영구 양전하). **알코올과 분류 기준이 다르다** — 알코올은 OH가 붙은 **탄소**의 차수, 아민은 **질소**에 붙은 R의 개수. 흔한 혼동 지점.
- **구조**: sp³, 삼각뿔형, 결합각 **~107°**(NH₃ 106.7°), 비공유쌍 1개.
- **염기성**: 비공유쌍이 H⁺를 받음. 세기는 **짝산의 pKa(pKaH)**로 표시 — 클수록 강염기.
  | 화합물 | pKaH |
  |---|---|
  | 암모니아 | 9.3 |
  | 1° 알킬아민 (EtNH₂) | **10.7** |
  | 2° 알킬아민 | 11.0 |
  | 3° 알킬아민 | 10.7 (용매화로 상승 정체) |
  | **아닐린 (방향족)** | **4.6** |
  | 피리딘 | 5.2 |
  | **아마이드** | **~ −0.5** (사실상 비염기성) |
  - **아닐린이 10⁶배 약염기인 이유**: N 비공유쌍이 **벤젠 π계와 공명 비편재화** → 양성자를 주려면 그 안정화를 포기해야 함. (양성자화된 아닐리늄에는 그 공명이 없다.)
  - **아마이드가 비염기성인 이유도 같은 원리**(카보닐과의 공명, →Ch10).
  - 기체상에서는 3° > 2° > 1° (순수 유도효과), 수용액에서 역전 — **용매화(N–H가 많을수록 양이온이 물에 잘 싸임)**가 순서를 바꾼다. 유도효과만으로 설명하면 틀린다.
- **아민의 물성**: N–H 수소결합(O–H보다 약함) → bp가 알코올보다 낮고 알케인보다 높음. 3° 아민은 N–H가 없어 급락.

## 아민 우산 반전(nitrogen inversion)
- 삼각뿔 ⇌ 평면 전이상태(sp²) ⇌ 뒤집힌 삼각뿔.
- **장벽 ~6 kcal/mol** (NH₃ 5.8) → 실온에서 초당 ~10¹¹회. 따라서 서로 다른 세 치환기 + 비공유쌍을 가진 아민은 **원리적으로는 카이랄이지만 분할 불가능**.
- **예외(분할 가능한 경우)**: ① **4급 암모늄 염**(비공유쌍이 없어 반전 불가) ② 고리 안에 갇힌 N(아지리딘류, 장벽 상승) ③ 인(포스핀)은 장벽 ~30 kcal/mol이라 **분할 가능**.
- 요점: **"카이랄이 아니다"가 아니라 "빠르게 라세미화된다"**.

## 규칙·메커니즘
- **알킬화(Sₙ2)**: RNH₂ + R′X → 2° 아민 → 계속 진행해 **과알킬화(3°, 4급까지)**. 생성물이 반응물보다 더 좋은 친핵체라서 멈추지 않는다 → **1° 아민 합성법으로 부적합**.
  - 우회로: ① **가브리엘 합성**(프탈이미드) ② **아자이드 환원**(RX + N₃⁻ → RN₃ → LiAlH₄) ③ **환원적 아민화**(카보닐 + 아민 → 이민 → NaBH₃CN 환원) ④ **아마이드 환원**(LiAlH₄).
- **호프만 제거**: 4급 암모늄 수산화물 가열 → **덜 치환된 알켄(Hofmann 생성물)**. –NR₃⁺가 부피 큰 이탈기이므로(→Ch6).
- **아민의 EAS**: –NH₂는 **최강의 활성화기 + o,p-지향**(→Ch4). 너무 활성이라 브로민화가 삼치환까지 감 → **아세틸화로 활성 조절**(–NHAc) 후 반응, 나중에 가수분해. 보호기 전략(→Ch9 아세탈과 같은 사고).

## 디아조 화학
- **디아조화**: **1° 방향족 아민** + HONO(NaNO₂/HCl), **0–5 °C** → **아렌다이아조늄 염 Ar–N₂⁺Cl⁻**.
  - **저온 필수** — 실온 이상에서는 N₂를 잃고 분해(페놀 생성). 안정한 물질이 **아니다**.
  - 1° **지방족** 아민은 즉시 N₂를 잃고 카보양이온이 되어 잡탕이 됨 → 합성에 무용.
- **디아조늄의 가치 = 치환기 변환 허브**(Sandmeyer 등):
  - Ar–N₂⁺ → **ArCl/ArBr/ArCN** (CuCl/CuBr/CuCN), **ArI** (KI), **ArF** (HBF₄, Schiemann), **ArOH** (H₂O/Δ), **ArH** (H₃PO₂ — 지향기를 쓰고 제거하는 전략).
  - EAS로는 직접 넣을 수 없는 치환기(–CN, –I, –F, –OH)를 도입하는 **유일한 실용 경로**.
- **디아조 짝지음(azo coupling)**: Ar–N₂⁺는 **약한 친전자체** → **강하게 활성화된 고리**(페놀, 3° 방향족 아민)와만 EAS. p 위치 우선. 생성물 **아조 화합물 Ar–N=N–Ar′**는 확장된 콘주게이션 → **가시광 흡수 = 염료**(→Ch12 UV-Vis).
  - pH 조건: 페놀은 약염기성(페녹사이드가 더 활성), 아민은 약산성(과산성이면 암모늄이 되어 비활성) — 좁은 창.

## 왜 이 예제인가
- **아닐린 vs 사이클로헥실아민**: pKaH 4.6 vs 10.6 — 공명의 크기를 고립 측정(Ch7의 페놀 대비와 정확히 대칭 구조: 공명이 산도는 올리고 염기도는 내린다).
- **아민 알킬화의 과반응**: "반응이 되는 것"과 "합성에 쓸 수 있는 것"이 다르다는 첫 명확한 사례.
- **디아조늄 → ArF/ArI**: EAS의 한계를 우회하는 설계. 합성 전략이 반응 목록 이상임을 보임.
- **4급 암모늄의 분할 가능성**: 우산 반전이 "카이랄성 부재"가 아니라 "속도 문제"임을 증명하는 대조군.

## ⚠ 원문 교정
1. **"극도로 안정한 유기 아릴 디아조늄 염"** — **틀렸다.** 아렌다이아조늄 염은 **0–5 °C에서만 다룰 수 있고**, 실온에서 분해되며 건조 고체는 폭발성이다. 원문 문장은 같은 문장 안에서 "N₂ 이탈 능력이 최상"과 "극도로 안정"이 모순된다. 정확히는 **"이탈기로서 N₂가 탁월해 반응성이 높고, 그래서 저온 유지가 필수"**.
2. **아민 우산 반전을 "에너지를 거의 소모하지 않고"** — 장벽은 **~6 kcal/mol로 0이 아니다**. 그리고 예외(4급 암모늄, 포스핀, 고리 아민)를 명시하지 않으면 "질소는 절대 카이랄이 될 수 없다"는 잘못된 일반화가 남는다.
3. **아민 분류(1°/2°/3°/4급)가 없음** — 이 단원의 기본 어휘가 빠졌고, 알코올과 기준이 다르다는 핵심 혼동 지점도 다뤄지지 않는다.
4. **염기성 수치·용매화 효과 누락** — "지방족 > 방향족"만 있고 왜 수용액에서 3°가 2°보다 약한지(용매화) 설명이 없다. 유도효과만 배운 학생은 반드시 틀린다.
5. **아민 합성법이 통째로 없음**(가브리엘·환원적 아민화·아자이드). 과알킬화 문제도 없다.
6. **호프만 제거 누락** — Ch6의 Hofmann 생성물이 실제로 등장하는 자리다.
7. **디아조늄의 Sandmeyer 계열 변환이 없음** — 디아조 짝지음(염료)만 있고, 디아조늄의 합성적 가치 대부분이 빠졌다.
8. **디아조 짝지음을 "가역 결합"이라 서술** — 아조 결합 형성은 EAS이며 **비가역**이다.

## ⚙ mol-craft 접점
- `[가능]` 아민 기하: `N_3` theta0 = **106.70°**, `electronDomains(N) = 3+1 = 4` → **삼각뿔형으로 붙는다**. `geometryName()`이 '삼각뿔형'을 반환. `presets.ammonia` 존재, `validation.test.js`가 103–110° 수렴을 검증.
- `[가능]` **비공유쌍 시각화**: `slotKinds()`가 남은 자리를 `'lonepair'`로 분류해 **보라색 구**로 그린다(`LONE_PAIRS.N = 1`). 아민의 비공유쌍이 왜 염기성의 자리인지 **그림으로 가리킬 수 있는 몇 안 되는 기능** — 이 장에서 가장 직접적인 교육 자산.
- `[가능→구현 가능]` **우산 반전 시연**: N을 평면으로 밀어 넣고(`setDihedral` 또는 좌표 직접 조작) `minimize`하면 삼각뿔로 복원. 평면 전이상태의 에너지 차를 `energy()`로 재면 **~6 kcal/mol 근처가 나오는지 검증할 가치가 있다**(UFF가 이 값을 맞추는지는 미확인 — 확인 후 맞으면 강력한 데모, 안 맞으면 한계로 명시).
- `[부분]` **아닐린 기하가 틀린다**: 아닐린의 N은 공명으로 **거의 sp² 평면**에 가까운데(실측 피라미드각 작음), mol-craft는 `N_3`(sp³ 106.7°)로 처리한다 — **Ch10의 아마이드와 정확히 같은 원인·같은 해법**(sp² 공액 인식 규칙). 두 장이 같은 코드 개선을 요구한다.
- `[불가]` 염기성·pKaH — README 배제 범위.
- `[불가]` 4급 암모늄(양전하), 디아조늄(양전하 + N≡N⁺), 아조 염료의 색(UV-Vis는 양자 영역).
- `[불가]` 우산 반전의 **속도**(장벽 높이는 낼 수 있으나 반응 속도론은 없음).
