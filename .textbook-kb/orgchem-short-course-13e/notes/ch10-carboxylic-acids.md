# Ch10. Carboxylic Acids and Their Derivatives

## Presupposes
Ch1: 공명, 형식전하. Ch4: 공명에 의한 음이온 안정화. Ch6: 이탈기 능력. Ch7: 유도/공명 효과, 산도. Ch9: 사면체 중간체, 엔올레이트.

## 개념 — 카복실산
- **–COOH**: 카보닐 + 하이드록시가 같은 탄소에. sp², 평면.
- **pKa ≈ 4.8** (아세트산). 알코올(16)보다 **10¹¹배 강산**. 두 원인:
  1. **공명**(주) — 카복실레이트 RCOO⁻의 음전하가 **등가인 두 산소에 완전 분산**. 두 C–O 결합 길이가 같아짐(1.26 Å, 단일 1.34/이중 1.20의 중간) — 직접 증거.
  2. **유도**(보) — 카보닐 산소의 전자 끌기.
- **치환기 효과(유도)**: 전자 끌개가 가까울수록 산도 ↑
  | 산 | pKa |
  |---|---|
  | 아세트산 CH₃COOH | 4.76 |
  | 클로로아세트산 ClCH₂COOH | 2.86 |
  | 다이클로로 Cl₂CHCOOH | 1.29 |
  | 트라이클로로 Cl₃CCOOH | 0.65 |
  | 3-클로로프로판산 | 4.0 (거리 멀어져 효과 감소) |
  - **유도 효과의 거리 감쇠**를 정량으로 보여주는 표준 데이터셋.
- **이량체**: 카복실산은 수소결합 2개로 **환형 이량체**를 이룸 → bp가 예상보다 높음.

## 유도체 — 반응성 서열이 이 장의 뼈대
`R–CO–L`에서 L이 무엇인가로 분류. **반응성은 ① L의 이탈기 능력 ② L의 공명 공여로 카보닐이 얼마나 안정화되는가**로 결정.

| 유도체 | L | 상대 반응성 | 비고 |
|---|---|---|---|
| 아실 할라이드 | –Cl | **최고** | Cl⁻ 우수 LG, 공명 공여 미미 |
| 산 무수물 | –OCOR | 높음 | |
| 에스터 | –OR | 중간 | |
| 카복실산 | –OH | 중간 | 염기성 조건에선 탈양성자화로 비활성 |
| **아마이드** | –NR₂ | **최저** | N의 강한 공명 공여 |
| (카복실레이트) | –O⁻ | 사실상 무반응 | |

- **핵심 규칙: 반응성이 높은 것 → 낮은 것으로만 변환된다**(내리막 방향). 아마이드에서 아실 할라이드로는 직접 못 간다. 합성 설계의 방향성을 정하는 규칙.
- **아마이드의 특수성**: N 비공유쌍이 C=O와 공명 → **C–N 결합이 부분 이중결합** → **회전 장벽 ~15–20 kcal/mol**, 아마이드기 전체가 **평면 고정**. 이것이 단백질 펩타이드 결합의 평면성(→Ch17 2차 구조)의 직접 원인이다. 또한 **아마이드는 염기성이 거의 없다**(N의 비공유쌍이 공명에 묶임) — 아민(pKaH ~10)과 결정적 차이.

## 규칙·메커니즘 — 친핵성 아실 치환
**첨가–제거 2단계**(Ch9의 순수 첨가와 다른 점):
1. Nu⁻가 카보닐 탄소 공격 → **사면체 중간체**(sp³, 알콕사이드).
2. C–O⁻가 이중결합으로 복원되며 **L⁻ 축출**.
- Ch9(알데하이드/케톤)에서 첨가가 거기서 멈추는 이유는 **H⁻나 R⁻이 이탈기로 나갈 수 없기 때문**. 유도체는 나갈 수 있는 L이 있어 치환으로 끝난다. **두 장의 차이가 이 한 문장에 있다.**

### 대표 반응
- **에스터화(Fischer)**: RCOOH + R′OH ⇌ RCOOR′ + H₂O, 산 촉매, **가역** → 과량 알코올 또는 물 제거로 이동.
- **비누화(saponification)**: 에스터 + NaOH(수성) → **RCOO⁻Na⁺ + R′OH**. **비가역** — 마지막 단계에서 카복실산이 탈양성자화되어 카복실레이트가 되고, 이는 친핵성 공격을 더 받지 않기 때문. **염기가 촉매가 아니라 소모되는 반응물**이라는 점이 산 촉매 가수분해와의 결정적 차이.
- **아마이드 형성**: 카복실산 + 아민을 단순 혼합하면 **산-염기 반응(염)**만 일어난다. 실제로는 아실 할라이드/무수물을 쓰거나 DCC 같은 축합제 필요. 원문의 "가열 탈수"는 강제 조건.
- **클라이젠 축합**: 에스터 엔올레이트 + 다른 에스터 → **β-케토 에스터**.
  - 염기는 **에스터의 알콕사이드와 같은 것**을 써야 함(EtO⁻ + 에틸 에스터) — 다른 것을 쓰면 에스터 교환이 일어남.
  - **완전한 당량의 염기가 필요**: 마지막에 생성물 β-케토 에스터의 α-H(pKa ~11)가 탈양성자화되며 평형이 끌려간다. **이 마지막 탈양성자화가 반응의 추진력**이다.
  - 분자 내 버전 = **디크만 축합**(5·6원 고리).

## 왜 이 예제인가
- **클로로아세트산 계열 pKa 사다리**: 유도 효과의 크기와 거리 감쇠를 동시에 정량화하는 유일한 깔끔한 데이터.
- **아세트산 이량체**: 수소결합이 물성(bp)뿐 아니라 분자의 실효 크기를 바꾼다.
- **비누화 vs Fischer 에스터화**: 같은 결합을 만들고 끊는데 한쪽만 가역 → **가역성이 평형이 아니라 마지막 단계의 산-염기에서 결정됨**을 보임.
- **아마이드 회전 장벽**: 공명이 "안정화"만이 아니라 **기하학적 구속**을 만든다는 것. Ch17로 직행하는 다리.

## ⚠ 원문 교정
1. **클라이젠 축합의 "에스터 알파 수소를 에스터 음이온 염기로 **탈수**하여"** — 오류. **탈양성자화(deprotonation)**다. 탈수(dehydration)는 물이 빠지는 것으로 전혀 다른 과정. (Ch7의 "환원 제거" 오류와 같은 계열의 용어 혼동 — 요약본 전반에 산-염기 과정을 다른 이름으로 부르는 경향이 있다.)
2. **유도체 반응성 서열이 없음** — 이 단원의 조직 원리 자체가 빠졌다. 유도체를 "군"으로 나열만 하고 **왜 그 순서인지, 어느 방향으로만 변환 가능한지**가 없으면 합성 설계를 할 수 없다.
3. **비누화가 비가역인 이유가 없음** — "비가역적으로 가수분해"라고 결과만 서술. 원인(마지막 탈양성자화)이 빠지면 Fischer 에스터화와의 차이를 이해할 수 없다.
4. **아마이드 회전 장벽의 수치와 그 귀결(평면성)** — 원문은 "단일 결합 회전이 저항을 받는다"고만 하고, 이것이 단백질 2차 구조의 원인임을 연결하지 않는다.
5. **클라이젠 축합에서 "완전 당량 염기 + 마지막 탈양성자화가 추진력"이 누락** — 왜 촉매량으로 안 되는지 설명 불가.
6. **카복실산 pKa 수치와 치환기 효과 표가 없음**(원문 부록에 "pKa ~4–5"만 등장).
7. "산 무수물 = 두 카복시산이 **수소 한 분자**를 빼며" — **물 한 분자**다. 단순 오타로 보이나 화학식 계산이 틀어진다.

## ⚙ mol-craft 접점
- `[가능]` **아마이드 평면성 시연 — 이 장 최고의 활용처**: 아마이드를 조립하면 N은 `N_3`(sp³, theta0 106.7°)로 타입된다. 실제 아마이드 N은 **sp² 평면**이어야 하는데 mol-craft는 이를 인식하지 못한다 → **현재 코드로는 틀린 기하가 나온다.**
  - 원인: `typeAtom()`이 **최대 결합 차수**로만 혼성을 정한다(`uff.js:31`). 아마이드 N은 단일결합만 가지므로 `N_3`. 공명에 의한 sp² 승격 규칙이 없다.
  - 해결 경로: `aromatize()`와 같은 방식의 **국소 공명 인식** — "sp³ N/O가 sp² 카보닐 탄소에 결합돼 있으면 `N_R`/`O_R`로 승격"하는 규칙. 이렇게 하면 아마이드 평면성, 에스터 평면성, 엔아민, 아닐린(→Ch11)이 한꺼번에 맞아떨어진다. **`sp2_conjugation` 확장은 Ch4·10·11·17을 동시에 고치는 최고 레버리지 개선안.**
  - 검증 방법: 아마이드 C–N 이면각을 `scanDihedral`로 스캔 → 현재는 낮은 장벽(sp2–sp3 규칙: V=1.0, n=6), 수정 후에는 sp2–sp2 규칙으로 큰 장벽이 나와야 함.
- `[가능]` 카복실산 기하: –COOH 조립 시 C=O(`O_2`, 120°)와 C–O–H(`O_3`, 104.51°)가 **다른 각도**로 나온다 → 카복실레이트가 되면 둘이 같아진다는 공명의 귀결을 **보여줄 수는 없다**(음전하 미지원).
- `[가능]` 카복실산 이량체: 두 분자를 배치해 O–H···O 거리를 잴 수는 있으나 **인력이 없어 안정 구조로 수렴하지 않는다**(정전기 항 부재).
- `[불가]` 산도·pKa — README가 명시적으로 배제.
- `[불가]` 카복실레이트(음전하), 사면체 중간체, 반응성 서열.
- `[주의]` 유도체 간 반응성 비교를 UFF 에너지로 시도하면 안 됨(위상이 다름 — Ch9 주의사항과 동일).
