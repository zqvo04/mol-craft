# Ch1. Bonding and Isomerism

## Presupposes
없음(진입점). 주기율표·전자껍질·전기음성도의 존재만 가정.

## 개념
- **원자가 전자**: 최외각 껍질 전자. 2주기 원소는 옥텟(8e) 목표. 3주기 이하는 d 오비탈 참여로 옥텟 초과 가능(초원자가).
- **이온결합 ↔ 공유결합은 이분법이 아니라 연속체**. ΔEN(Pauling) ≳ ~1.7~2.0을 관례적 경계로 쓰지만 임의값이다. 실제로는 전자 밀도가 얼마나 치우쳤는가의 정도 문제.
- **극성 공유결합**: ΔEN > 0 → δ⁺/δ⁻. 결합 쌍극자 μ = q·d (단위 D, 1 D = 3.336×10⁻³⁰ C·m). **분자 쌍극자는 결합 쌍극자의 벡터합** — CO₂는 극성 결합 2개인데 분자는 무극성(180° 상쇄), H₂O는 굽은형이라 합이 남는다. 결합 극성 ≠ 분자 극성.
- **Catenation**: C–C 결합 에너지(~83 kcal/mol)가 크고 C가 4가라 장쇄·고리 형성이 가능. Si는 Si–Si가 약해(~53) 장쇄가 불안정 — 탄소 화학이 특별한 이유.
- **원자가(중성·형식전하 0 기준)**: H 1 · C 4 · N 3 · O 2 · F/Cl/Br/I 1 · S 2 · P 3 · B 3.
- **형식 전하** FC = V − N − B
  - V = 중성 원자의 원자가 전자 수, N = 비공유 **전자 수**(쌍이 아니라 전자 개수), B = **결합 수(결합차수 합)**.
  - 등가식: FC = V − N − ½(결합 전자 수). 이중결합은 B에 2로 센다.
  - 검산: H₃O⁺의 O → 6 − 2 − 3 = +1. NH₄⁺의 N → 5 − 0 − 4 = +1. 카복실레이트의 두 O → 하나는 6−4−2=0, 하나는 6−6−1=−1.
- **공명 구조**: **원자 위치는 고정, 전자(π·비공유쌍)만 재배치**한 둘 이상의 루이스 구조. 실제 분자는 기여 구조들 사이를 오가지 않는다 — 어느 기여 구조와도 다른 **단일한 혼성체**다(노새가 말과 당나귀를 오가지 않는 것과 같음).
  - 기여도 순위: ① 옥텟 최대 만족 ② 형식전하 절대값 최소 ③ 음전하는 더 전기음성인 원자에 ④ 같은 부호 전하가 인접하지 않음.
- **σ 결합**: 핵간축 방향 종단 중첩. 축 대칭이라 **회전해도 중첩이 줄지 않음 → 자유 회전**(Ch2 배좌의 근거).
- **sp³ 혼성**: 2s + 2p×3 → 등가 오비탈 4개, 정사면체각 **109.47°**(=arccos(−1/3)). 109.5°는 반올림.

## 보강 — 원문에 없지만 필수: 불포화도(DoU)
분자식만으로 π결합+고리의 총수를 결정:
```
DoU = (2c + 2 + n − h − x) / 2      (c=C, n=N, h=H, o=O는 무관, x=할로젠)
```
- C₆H₆ → (12+2−6)/2 = 4 (고리1 + π3 = 벤젠)
- 산소는 식에 들어가지 않는다(2가라 골격을 늘릴 뿐 불포화도를 안 바꿈).
- **분자 그래프에서 직접 계산 가능** → mol-craft가 구조식만으로 검증할 수 있는 몇 안 되는 "정답이 있는" 양.

## 개념 분류축
- **이성질체**: 분자식 동일, 배열 상이.
- **구조(연결성) 이성질체**: 연결 그래프 자체가 다름 → 별개의 화합물(끓는점·반응성 전부 다름).
- 골격 분류: 비고리형 / 탄소고리형 / 헤테로고리형.
- **작용기**: 탄소 골격과 무관하게 반응성을 결정하는 원자단. 유기화학 전체가 "작용기별 반응 목록"으로 조직되는 이유.

## 왜 이 예제인가
- **H₃O⁺ / NH₄⁺**: 형식전하가 "원자가가 틀렸다"가 아니라 "전자 회계 결과"임을 보여줌. 원자가 상한만 보는 프로그램은 이걸 오류로 오판한다.
- **CO₂ vs H₂O**: 결합 극성과 분자 극성의 분리. 기하가 물성을 결정하는 첫 사례.

## ⚠ 원문 교정
1. **형식전하 공식의 "비공유 전자 수"** — 쌍(pair)이 아니라 **전자 개수**다. 원문 표기가 모호해 그대로 옮기면 절반 값이 나온다.
2. **"원자가 = 옥텟 만족에 필요한 전자 수"** — 2주기에서만 참. S(6가), P(5가), 할로젠(최대 7가)은 옥텟을 넘는다. mol-craft가 `EXPANDED_VALENCE`를 따로 두는 이유와 정확히 같은 지점.
3. **공명을 "기여 구조들의 평균"**이라 쓴 것 — 산술 평균이 아니라 **가중 중첩**이며, 혼성체는 어느 기여 구조보다도 **에너지가 낮다**(공명 안정화). "평균"이라고만 하면 안정화 에너지가 왜 생기는지 설명되지 않는다.
4. 원문은 sp³만 다루고 sp²/sp를 Ch3로 미룬다 — 혼성 개념의 완결은 Ch3와 함께 봐야 한다.

## ⚙ mol-craft 접점
- `[가능]` 원자가 상한 강제: `params.js: MAX_VALENCE` + `EXPANDED_VALENCE`, `snap.js: canBond()`가 클릭 자체를 차단. 교정 ②가 이미 코드에 반영돼 있음.
- `[가능]` sp³ 109.47°: `IDEAL_ANGLES[4]`, `UFF_PARAMS.C_3.theta0`. 정사면체각이 데이터로 존재.
- `[가능]` 분자식: `snap.js: formula()` (Hill 표기).
- `[가능→미구현]` **구조 이성질체 판별**: 같은 `formula()` + 다른 `uff.topologyKey()`면 구조 이성질체다. 판정에 필요한 함수가 **이미 전부 있는데 UI가 없다** — 학습 기능으로 가장 저비용/고효용인 후보.
- `[가능→미구현]` **DoU**: `bondOrderSum`과 원소 개수만으로 즉시 계산 가능. 사용자가 그린 구조의 자기검증 지표로 쓸 수 있음.
- `[부분]` 전기음성도: `UFF_PARAMS.chi`(GMP 척도)가 존재하나 **결합 길이 보정(`bondLength`의 `rEN`)에만** 쓰인다. δ⁺/δ⁻ 시각화나 분자 쌍극자 계산에는 미사용.
- `[불가]` **형식 전하**: `mol.atoms`에 `charge` 필드가 없다. H₃O⁺·NH₄⁺·카복실레이트를 표현할 수 없고, `LONE_PAIRS`가 중성 기준 고정 상수라 이온에서는 틀린 자리를 그린다. → 이온·산염기·메커니즘(Ch6·9·10) 전체를 막는 **최상위 구조적 제약**.
- `[불가]` **공명**: `aromatize()`가 방향족 고리를 order 1.5로 승격하지만, 이는 방향족 한정이며 알릴/카복실레이트/엔올레이트 같은 비고리 공명계는 케쿨레 한 장으로 고정된다. 기여 구조 전환 UI 없음.
- `[불가]` 분자 쌍극자 벡터합 — 부분전하 항이 UFF에서 빠져 있어(README 명시) 계산 근거 자체가 없음.
