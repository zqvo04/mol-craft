# Ch16. Carbohydrates

## Presupposes
Ch2: 의자 형태, axial/equatorial, A-value. Ch5: 카이랄성, 피셔 투영식, 부분입체 이성질체, R/S. Ch9: 헤미아세탈·아세탈, 카보닐. Ch12: NMR 등가성.

## 개념 — 분류
- **탄수화물**: 다수의 –OH를 가진 **알데하이드(알도스)** 또는 **케톤(케토스)**. 실험식 Cₙ(H₂O)ₙ에서 유래한 이름이지만 "수화된 탄소"라는 뜻은 아님.
- 분류 축 3개를 조합: **카보닐 종류**(알도/케토) × **탄소 수**(트라이오스~헥소스) × **배열**(D/L).
- **D/L 표기(피셔 투영식 기준)**: 카보닐을 위쪽에 두고, **카보닐에서 가장 먼 입체중심**의 –OH가 **오른쪽이면 D, 왼쪽이면 L**.
  - **자연계 당은 거의 전부 D**(아미노산은 거의 전부 L — 대칭적 편향).
  - **D/L은 R/S와 별개 체계**이며 상호 변환이 자동이 아니다. D-글리세르알데하이드 = (R). 다만 **다른 당에서 D가 반드시 R인 것은 아니다**.
- **에피머**: 여러 입체중심 중 **정확히 하나**만 다른 부분입체 이성질체. D-글루코스와 D-만노스는 **C2 에피머**, D-갈락토스는 **C4 에피머**.
- 알도헥소스는 입체중심 4개 → **2⁴ = 16개**(D형 8 + L형 8). 글루코스는 그중 하나.

## 고리형 구조 — 이 장의 중심
- **분자 내 헤미아세탈**(→Ch9): C5–OH가 C1 알데하이드를 공격 → **6원 고리(피라노스)**. C4–OH면 5원(**푸라노스**).
  - Ch9에서 "헤미아세탈은 보통 불안정"이라 했는데, **분자 내 5·6원 고리는 안정**하다 — 엔트로피 손실이 작기 때문. 그래서 당은 수용액에서 **>99% 고리형**.
- **아노머 탄소**: 고리화로 **새로 생긴 입체중심**(알도스의 C1). 헤미아세탈 탄소 = **–OH와 –OR을 동시에 가진 유일한 탄소** → 구조에서 즉시 식별 가능.
- **α / β 아노머**: 하워스 투영식에서 아노머 –OH가 **아래쪽이면 α, 위쪽이면 β**(D-당 기준). 정확한 정의는 **아노머 –OH가 D/L 지시 탄소의 –OH와 같은 쪽이면 α**.
- **의자 형태에서의 결정적 사실**: **β-D-글루코피라노스는 –OH와 –CH₂OH가 **전부 equatorial**.**
  - 이것이 글루코스가 자연계에서 가장 흔한 당인 이유 — **가능한 알도헥소스 16종 중 유일하게 모든 치환기를 equatorial로 놓을 수 있다**(Ch2의 A-value가 여기서 결과를 낳는다).
  - α 아노머는 C1–OH가 axial → 불안정. 그래서 수용액 평형은 **β 64% : α 36%**(열린 사슬 0.02%).
- **변선광(mutarotation)**: 순수 α 또는 β 결정을 물에 녹이면 고리가 열렸다 닫히며 평형에 도달 → 비선광도가 서서히 변해 수렴(α +112° / β +19° → +52.7°). **고리-사슬 평형의 직접 관측 증거.**

## 반응
- **글리코사이드**: 헤미아세탈 + 알코올(산 촉매) → **아세탈**(→Ch9). 아노머 –OH가 –OR로.
  - **아세탈이므로 더 이상 고리가 열리지 않는다** → **변선광 없음, 환원성 없음**. 이것이 글리코사이드 결합의 안정성 근거이자 다당류가 존재할 수 있는 이유.
- **환원당 / 비환원당**: 유리 아노머 탄소(헤미아세탈)가 있으면 열린 사슬 알데하이드로 갈 수 있어 **Tollens/Fehling/Benedict 시약을 환원**. 아세탈로 잠기면 비환원당.
  - 말토스·락토스 = 환원당 / **수크로스 = 비환원당**(두 아노머 탄소가 서로 결합).
- **에스터화·에터화**: –OH들의 일반 알코올 반응.

## 이당류·다당류
| 당 | 구성 | 결합 |
|---|---|---|
| 말토스 | Glc + Glc | **α(1→4)** |
| 셀로바이오스 | Glc + Glc | **β(1→4)** |
| 락토스 | Gal + Glc | β(1→4) |
| 수크로스 | Glc + Fru | **α(1→2)β** (양쪽 아노머 탄소) |
| 아밀로스(녹말) | Glc | **α(1→4)** → 나선형, 소화 가능 |
| 셀룰로스 | Glc | **β(1→4)** → **직선 사슬, 사슬 간 수소결합 → 섬유** |
| 글리코젠 | Glc | α(1→4) + α(1→6) 가지 |
- **α vs β (1→4)의 결과가 이 장의 절정**: 같은 단량체(글루코스), 같은 결합 위치, **아노머 배치 하나 차이**로 녹말(식량)과 셀룰로스(목재)가 갈린다.
  - β 결합은 인접 단위를 **180° 뒤집어** 연결 → 곧은 리본 → 사슬 간 수소결합 촘촘 → 결정성 섬유, 물에 안 녹음.
  - α 결합은 꺾여 **나선**을 이룸 → 밀집 못 함 → 소화 효소 접근 가능.
  - 인간은 β-글리코시데이스가 없어 셀룰로스를 소화 못 함(반추동물은 공생 미생물이 처리).

## 왜 이 예제인가
- **β-D-글루코피라노스의 전-equatorial 배치**: Ch2의 배좌 분석이 **왜 이 당이 선택되었는가**라는 생물학적 질문에 답하는 순간. 유기화학에서 가장 아름다운 구조-기능 논증.
- **변선광**: 눈에 보이지 않는 평형을 편광계로 실시간 관측 — 개념이 측정 가능해지는 사례.
- **수크로스의 비환원성**: 아세탈/헤미아세탈 구분(Ch9)이 실험 결과(Fehling 음성)로 직결.
- **녹말 vs 셀룰로스**: 단일 입체중심 차이의 거시적 귀결 — Ch5 입체화학의 최종 정당화.

## ⚠ 원문 교정
1. **α/β 아노머를 "아노머 탄소의 하이드록시 지향에 따라"라고만 서술** — 기준(D/L 지시 탄소와 같은 쪽/반대쪽, 하워스에서 아래/위)이 없어 **실제로 배정할 수 없다**.
2. **β-D-글루코스의 전-equatorial 배치와 그 귀결이 없음** — 이 장에서 Ch2와 연결되는 **가장 중요한 사실**이 빠졌다. 왜 글루코스가 자연계의 기본 당인지 설명할 수단이 사라진다.
3. **α/β 글리코사이드 결합이 녹말/셀룰로스를 가른다는 사실이 없음** — 이당류를 나열만 하고(말토스·락토스·수크로스) **결합 유형과 그 물성 귀결**이 통째로 빠졌다. 다당류 자체가 거의 없다.
4. **환원당/비환원당 개념 누락** — 아노머 탄소가 자유인가 잠겼는가라는 판정 기준이 없어, 글리코사이드의 의의(변선광 소실)가 결과로 연결되지 않는다.
5. **케토스(프럭토스)가 사실상 없음** — 수크로스의 구성 성분인데 다루지 않는다.
6. **D/L과 R/S의 관계** — 원문은 D/L을 "고전 표기 기준"이라 하고 넘어가는데, **두 체계가 독립적**이며 D가 R을 뜻하지 않는다는 점을 명시하지 않으면 Ch5와 충돌한다.
7. **변선광의 평형값(α 36 : β 64)과 그 원인(axial/equatorial)이 없음** — 현상만 있고 설명이 없다.
8. "아노머 탄소 = **최고의** C-1 비대칭 카이랄 탄소" — 의미 불명의 수사. 정확히는 "고리화로 **새로 생긴** 입체중심"이다.

## ⚙ mol-craft 접점
- `[가능]` **피라노스 고리 배좌 — 이 장 최고의 활용처**: `cyclohexane` 고리 템플릿(의자)에서 출발해 C 하나를 O로 바꾸고 –OH·–CH₂OH를 붙이면 글루코피라노스가 조립된다.
  - 치환기를 **axial/equatorial에 각각 배치**하고 `minimize` → 에너지 비교로 **β(전-equatorial)가 α보다 낮음을 실제로 계산할 수 있다**. **같은 위상(topology)이 아니라 같은 배치의 다른 배좌**이므로, Ch9에서 경고한 "위상 다른 분자 비교 금지"에 걸리지 않는 **정당한 UFF 사용**이다.
  - 단 α/β는 **배치(configuration)** 차이라 엄밀히는 부분입체 이성질체 = 위상은 같고 입체만 다름 → **UFF로 비교 가능**(거울상이 아니므로 에너지가 다르다). Ch5에서 지적한 "거울상은 에너지가 같다"는 제약에 걸리지 않는다. **이 장이 UFF의 유효 범위 안에 정확히 들어오는 드문 사례.**
- `[가능]` **α vs β 글리코사이드 결합의 사슬 형태**: 셀로바이오스(β)와 말토스(α)를 만들어 `minimize`하면 **직선 vs 꺾임**이 나온다. 4~6량체로 늘리면 셀룰로스의 곧은 리본과 아밀로스의 나선이 UFF 수준에서도 정성적으로 재현될 가능성이 높다. → **Ch5(입체) → Ch16(구조) → 물성**의 인과를 3D로 완주하는 데모.
- `[가능]` 헤미아세탈/아세탈 탄소 자동 식별: "같은 탄소에 –OH와 –OR" / "–OR 둘"은 **그래프 패턴 매칭으로 검출 가능** → **아노머 탄소 자동 표시, 환원당/비환원당 자동 판정**이 순수 그래프 연산으로 구현된다.
- `[불가→구현 가능]` **α/β 아노머 자동 판정**: 아노머 탄소 식별 + CIP(→Ch5) + 고리 평면 기준 방향 판정이면 배정 가능. Ch5 CIP 구현의 직접적 응용처.
- `[불가→구현 가능]` **axial/equatorial 자동 라벨링**: 고리 평면 법선과 치환기 방향의 각도로 분류. `findRings()` + `geom` 벡터 연산만 필요. **Ch2·Ch16이 공유하는 최우선 구현 후보.**
- `[주의]` `findRings()`가 정식 SSSR이 아님 → **이당류/다당류(고리 여러 개 + 글리코사이드 다리)에서 2D 골격식이 어긋날 수 있다**(Ch15와 동일 과제).
- `[불가]` 변선광(고리-사슬 평형, 결합 재배치), 비선광도, 환원 시험 반응.
- `[불가]` 수소결합 — **셀룰로스 사슬 간 수소결합망은 표현 불가**(정전기 항 부재). 단일 사슬의 **형태**까지만.
