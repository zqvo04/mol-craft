# Ch17. Amino Acids, Peptides, and Proteins

## Presupposes
Ch5: 카이랄성, R/S, 피셔 투영식. Ch7: 티올·이황화 결합, 산도. Ch10: **아마이드 공명·평면성·회전 장벽**. Ch11: 아민 염기성. Ch13: 이미다졸(히스티딘). Ch14: 사슬 간 수소결합.

## 개념 — 아미노산
- **α-아미노산**: 같은 탄소(α)에 –NH₂와 –COOH. 일반형 **H₂N–CHR–COOH**.
  - **20종 단백질생성 아미노산**. 글라이신(R=H)만 **아카이랄**, 나머지 19종은 카이랄이며 **거의 전부 L**(= 대부분 (S), 단 **시스테인만 (R)** — 곁사슬 S의 원자번호가 CIP 순위를 바꾸기 때문. Ch5 CIP 규칙이 실제로 물리는 지점).
- **곁사슬 R로 분류**: 비극성(Ala, Val, Leu, Ile, Phe, Met, Pro, Trp) / 극성 비하전(Ser, Thr, Cys, Asn, Gln, Tyr, Gly) / 산성(Asp, Glu) / 염기성(Lys, Arg, His).
  - **프롤린**: 곁사슬이 N과 고리를 이룸 → **2° 아민**, 아마이드 N–H가 없어 **수소결합 주개 불가** → α-나선·β-병풍을 **끊는다**("helix breaker").
  - **시스테인**: –SH → **이황화 결합**(→Ch7)으로 3차 구조 고정.
  - **히스티딘**: 이미다졸(→Ch13) pKa ≈ 6.0 → **생리 pH에서 유일하게 완충·산염기 촉매**로 작동. 효소 활성부위에 압도적으로 자주 등장하는 이유.

## 산-염기 성질
- **쯔비터이온**: 고체·중성 수용액에서 **–COO⁻ / –NH₃⁺**. 알짜 전하 0이지만 **이온성 물질** → 높은 mp(>200 °C, 분해), 물에 잘 녹음, 유기용매에 안 녹음. 중성 분자 형태(H₂N–CHR–COOH)는 사실상 존재하지 않는다.
- **pKa 값**: α-COOH ≈ **2.3**(옆의 –NH₃⁺ 유도효과로 아세트산 4.8보다 강산) / α-NH₃⁺ ≈ **9.6**.
- **등전점 pI**: 알짜 전하 = 0인 pH.
  - **곁사슬이 중성이면** pI = (pKa₁ + pKa₂)/2 ≈ 6.0
  - **산성 곁사슬(Asp/Glu)**: 두 개의 **산성** pKa 평균 → pI ≈ 3
  - **염기성 곁사슬(Lys/Arg/His)**: 두 개의 **염기성** pKa 평균 → pI ≈ 9.7–10.8
  - **규칙**: 알짜 0 상태를 만드는 **양쪽 pKa의 평균**. 이 원리를 알면 외울 필요가 없다.
- 응용: **전기영동**(pH에 따라 이동 방향/속도가 갈림), 이온교환 크로마토그래피.

## 펩타이드
- **펩타이드 결합 = 아마이드 결합**. 형성은 축합(–H₂O)이나 **열역학적으로 불리** → 생체에서는 ATP 활성화 + 리보솜, 실험실에서는 활성화제(DCC) + **보호기 전략**(Merrifield 고체상 합성).
- **평면성(→Ch10 직접 응용)**: C–N이 부분 이중결합(공명) → **Cα–C(=O)–N–Cα 6원자가 한 평면**, 회전 장벽 ~20 kcal/mol.
  - **거의 전부 trans**(cis는 곁사슬 충돌). **예외: X–Pro 결합은 cis가 ~10%** — 프롤린의 고리 때문에 cis/trans 에너지 차가 작다.
  - **결과: 주사슬의 자유도는 아마이드 평면 사이의 두 각 φ(N–Cα)와 ψ(Cα–C)뿐**이다. 단백질 구조 전체가 residue당 2개의 이면각으로 기술된다.
- **라마찬드란 도표**: (φ, ψ) 평면에서 입체적으로 허용되는 영역. α-나선(−57, −47), β-병풍(−120, +120) 부근에 군집. **순수한 입체 반발(vdW)만으로 허용 영역이 결정된다** — 계산으로 재현 가능한 대표 사례.
- **N-말단 / C-말단**: 서열은 **N → C** 방향으로 쓴다(관례).

## 단백질 구조 4계층
| 계층 | 내용 | 유지하는 힘 |
|---|---|---|
| **1차** | 아미노산 서열 | **공유결합**(펩타이드 결합) |
| **2차** | α-나선, β-병풍, 턴 | **주사슬 N–H···O=C 수소결합** |
| **3차** | 전체 3D 접힘 | 소수성 효과(주), 수소결합, 이온쌍, **이황화 공유결합** |
| **4차** | 소단위 회합 | 3차와 같은 비공유 힘 |
- **α-나선**: 오른손 나선, residue 3.6개/회전, **i → i+4 수소결합**, 피치 5.4 Å. 곁사슬은 바깥.
- **β-병풍**: 인접 가닥 사이 수소결합. **평행/역평행**. 역평행이 수소결합 기하가 더 좋아 안정.
- **3차 구조의 주 추진력은 소수성 효과** — 비극성 곁사슬이 안쪽으로 묻히며 **물의 엔트로피가 증가**하는 것이 주된 동인이다(곁사슬끼리의 인력이 아니다).
- **변성(denaturation)**: 열·pH·요소·계면활성제로 2~4차 구조 파괴. **1차 구조는 유지**. 리보뉴클레이스 재접힘 실험(Anfinsen) → **접힘 정보는 서열에 있다**.

## 왜 이 예제인가
- **시스테인이 유일한 (R)**: CIP 규칙(Ch5)이 "L = S"라는 편한 암기를 깨는 반례. 규칙을 규칙대로 적용해야 함을 강제.
- **프롤린**: 하나의 구조적 특징(고리 → 2° 아민 → N–H 없음)이 2차 구조 전체를 좌우 → 국소 화학이 거시 구조를 정한다.
- **히스티딘 pKa 6**: 20종 중 유일하게 생리 pH 근처 → 촉매 기능의 화학적 필연성.
- **라마찬드란 도표**: 실험 데이터(수천 개 구조)와 단순 vdW 계산이 일치 — 물리가 생물 구조를 예측함을 보이는 정점.
- **Anfinsen 실험**: 1차 → 3차의 정보 흐름을 실험으로 증명.

## ⚠ 원문 교정
1. **"펩티드 결합 = **가열 탈수 축합**"** — 오해를 부른다. 생체 내에서는 리보솜에서 **아미노아실-tRNA(활성화된 에스터)**를 거치며, 실험실에서도 축합제/활성화가 필요하다. 단순 가열로는 일어나지 않는다(열역학적으로 불리).
2. **아마이드 평면성의 귀결(φ/ψ 두 자유도)이 없음** — 원문은 Ch10에서 아마이드 회전 제약을 말하고 Ch17에서 "평면 공명성"이라 언급하지만, **그래서 단백질 주사슬이 residue당 이면각 2개로 기술된다**는 결정적 결론에 도달하지 않는다. 라마찬드란 도표도 없다.
3. **3차 구조의 주 추진력을 "정전기, 소수성 인력 및 디설파이드"로 병렬 나열** — **소수성 효과가 지배적**이고, 그것도 "인력"이 아니라 **물의 엔트로피 효과**다. 병렬 나열은 중요도와 기작을 모두 흐린다.
4. **pI 계산 방법이 없음** — "알짜 전하가 0인 pH"라는 정의만 있고 곁사슬 유무에 따른 계산 규칙이 빠져 문제를 풀 수 없다.
5. **20종 아미노산의 분류·개별 특성(프롤린·시스테인·히스티딘)이 통째로 없음** — 이 장의 실질적 내용 대부분.
6. **α-나선의 기하 수치(3.6 residue/회전, i→i+4, 5.4 Å)와 β-병풍의 평행/역평행 구분이 없음** — "규칙적 수소 결합으로 뒤틀려 접히는 구조"라는 서술로는 두 구조를 구별할 수 없다.
7. **L-아미노산이 대부분 (S)이지만 시스테인은 (R)** — 언급 없음. Ch5 CIP의 실전 적용점이 사라진다.
8. **변성·Anfinsen 실험 누락**.
9. **"N-말단은 최좌단, C-말단은 최우단"** — 표기 관례(N→C로 쓴다)의 결과일 뿐이며, 마치 물리적 배치인 것처럼 읽힌다.

## ⚙ mol-craft 접점
- `[가능→구현 가능, 최고 레버리지]` **아마이드 평면성 수정이 이 장의 전제**: 현재 `typeAtom()`은 아마이드 N을 `N_3`(sp³)로 판정한다(→Ch10 상세). **펩타이드 결합이 평면이 되지 않으므로 이 장의 어떤 것도 제대로 보여줄 수 없다.**
  - 수정: sp² 카보닐 탄소에 결합한 sp³ N/O를 `N_R`/`O_R`로 승격하는 **공액 인식 규칙**. `aromatize()`와 같은 자리(`model.js`)에 넣으면 된다.
  - 수정 후 검증: 다이펩타이드의 ω(Cα–C–N–Cα) 이면각을 `scanDihedral`로 스캔 → **180°(trans)와 0°(cis)에 두 최소, 90°에 큰 장벽**이 나와야 한다. `test/validation.test.js`에 추가할 만한 문헌 검증 항목.
- `[가능→구현 가능]` **φ/ψ 측정과 라마찬드란 도표**: `model.measure(mol, [C_{i-1}, N, Cα, C])` = φ, `measure(mol, [N, Cα, C, N_{i+1}])` = ψ. **이미 있는 함수로 바로 계산된다.**
  - 2차원 스캔(φ, ψ를 격자로 돌며 `energy()`)으로 **라마찬드란 도표를 직접 그릴 수 있다** — 다이펩타이드(~25원자) 규모면 계산량도 현실적(36×36 = 1296점).
  - **UFF의 vdW + 비틀림만으로 허용 영역이 나온다**(실제 라마찬드란도 본질적으로 입체 반발 계산). **mol-craft가 정량적으로도 신뢰할 만한 결과를 낼 수 있는, 이 교재 전체에서 가장 좋은 검증 과제.**
- `[가능]` 이황화 결합: S–S 이면각 ~90° 규칙이 UFF에 구현됨(→Ch7). 시스테인 두 개를 잇고 최적화하면 올바른 기하가 나온다.
- `[가능]` 아미노산 개별 구조 조립(20종 전부 C/N/O/S만 사용 — 지원 원소 안에 들어옴). **프리셋 라이브러리 후보로 최적**.
- `[부분]` **쯔비터이온을 표현할 수 없다** — `charge` 필드 부재(Ch1 이래 반복되는 최상위 제약). 아미노산의 **실제 존재 형태**를 그릴 수 없고, 중성 형태(존재하지 않는 형태)만 그리게 된다. **학습 도구로서 정직성 문제**가 생기는 지점 — 최소한 "이 도구는 중성 형태만 표시한다"는 경고가 필요.
- `[불가]` **2차 구조(α-나선·β-병풍)**: 주사슬 N–H···O=C **수소결합이 UFF에 없어** 나선이 자발적으로 형성되지 않는다. 나선 좌표를 **직접 지정해서 보여주는 것**은 가능하나(프리셋), `minimize`하면 풀려버릴 가능성이 높다. → **표시는 가능, 시뮬레이션은 불가**로 명확히 구분해야 함.
- `[불가]` 3차·4차 구조, 소수성 효과(용매 없음), pI·전기영동, 변성.
- `[불가]` 규모: 실제 단백질(수천 원자)은 vdW O(n²) + 수치 미분으로 불가능. **다이펩타이드~펜타펩타이드가 현실적 상한.**
