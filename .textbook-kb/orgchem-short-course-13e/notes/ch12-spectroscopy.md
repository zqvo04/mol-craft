# Ch12. Spectroscopy and Structure Determination

## Presupposes
Ch1: 결합, 대칭. Ch3: 콘주게이션. Ch4: 방향족. Ch5: 등가/비등가 개념. Ch7·9·10: 작용기 전반.

## 개념 — 분광학 전체 지도
| 기법 | 측정 대상 | 알려주는 것 |
|---|---|---|
| **¹H/¹³C NMR** | 핵스핀 전이(라디오파) | **탄소-수소 골격 연결성** — 가장 정보량 큼 |
| **IR** | 결합 진동(적외선) | **작용기 존재 여부** |
| **UV-Vis** | 전자 전이(자외/가시광) | **콘주게이션 정도** |
| **MS** | 이온 m/z | **분자량 + 분자식 + 조각 정보** |

## NMR
- 원리: 자기장 속에서 스핀 ½ 핵(¹H, ¹³C)의 두 스핀 상태가 갈라지고, 그 차이에 해당하는 라디오파를 흡수. **핵 주변 전자 밀도가 국소 자기장을 가림(shielding)** → 흡수 위치가 이동.
- **화학적 이동 δ (ppm)**: 기준 TMS = 0. **자기장 세기에 무관한 단위**라서 서로 다른 기기의 데이터를 비교할 수 있다(그래서 Hz가 아니라 ppm을 쓴다).
  - **탈가림(downfield, δ↑)** ← 전자 밀도 감소: 전기음성 원자 인접, sp² 탄소, **방향족 고리 전류**.
  - ¹H 대표값: TMS 0 · 알케인 0.9–1.5 · 알켄 인접 CH 1.7 · **CH–할로젠/O 3.3–4.5** · **알켄 H 4.6–5.9** · **방향족 H 6.5–8** · **알데하이드 H 9.5–10** · **카복실산 H 10–13**.
  - ¹³C: 알케인 0–50 · C–O 50–80 · 알켄/방향족 100–150 · **카보닐 165–220**.
- **적분값**: 신호 면적 ∝ **그 환경에 있는 H의 개수**(¹H만; ¹³C는 통상 적분 안 씀).
- **스핀-스핀 갈라짐**: 이웃 탄소의 H가 만드는 미세 자기장.
  - **n+1 규칙**: **화학적으로 등가인 이웃 H가 n개면 n+1개로 갈라진다.**
  - 세기 비 = 파스칼 삼각형(1:1 / 1:2:1 / 1:3:3:1).
  - **커플링 상수 J (Hz)**: 자기장에 무관. 커플링하는 두 신호의 J는 **같다** → 어느 신호끼리 이웃인지 짝 맞추기 가능. 알켄에서 **J_trans (12–18 Hz) > J_cis (6–12 Hz)** → **E/Z 판별에 직접 사용**.
  - **–OH, –NH는 보통 갈라지지 않음**(빠른 교환). D₂O 흔들기로 사라짐 → 확인 수단.
- **등가성 판정**: 대칭(회전축·거울면)으로 서로 겹치는 H는 등가. 신호 개수 세기가 구조 결정의 첫 단계.

## IR
- 원리: 결합의 신축·굽힘 진동이 적외선을 흡수. 진동수 ν̄ ∝ √(k/μ) — **결합이 셀수록(k↑), 원자가 가벼울수록(μ↓) 높은 파수**.
- 핵심 흡수대 (cm⁻¹):
  | 결합 | 파수 | 특징 |
  |---|---|---|
  | **O–H** (알코올) | 3200–3600 | **넓음**(수소결합) |
  | **O–H** (카복실산) | 2500–3300 | 매우 넓음, C–H와 겹침 |
  | **N–H** | 3300–3500 | 1°는 2개 봉우리, 2°는 1개 |
  | C–H | 2850–3000 (sp³) / 3000–3100 (sp²) | 3000 경계가 포화/불포화 판별선 |
  | **C≡N / C≡C** | 2100–2260 | 조용한 영역이라 보이면 확실 |
  | **C=O** | **1670–1780** | **가장 강하고 뾰족** — 진단 가치 최고 |
  | C=C | 1620–1680 | 약함 |
  - **C=O 세부 위치가 유도체를 구분**: 아마이드 1650 < 카복실산 1710 ≈ 케톤 1715 < 에스터 1735 < 아실 클로라이드 1800. **Ch10의 반응성 서열과 같은 순서** — 공명 공여가 클수록 C=O 결합차수가 낮아져 파수가 내려간다. 두 장이 같은 물리로 이어지는 지점.
  - 콘주게이션은 C=O를 ~30 cm⁻¹ 내린다.
- **지문 영역(1500 이하)**: 복잡해 개별 해석 불가하나 **물질 동정(지문 대조)**에는 결정적.

## UV-Vis
- π → π* 전이. **콘주게이션이 길수록 HOMO-LUMO 간격 ↓ → λmax ↑(장파장)**.
- 에텐 171 nm → 1,3-뷰타다이엔 217 → 헥사트라이엔 258 → β-카로틴(11 conj.) 450 nm(**가시광 → 주황색**).
- **색을 띠려면 대략 8개 이상의 콘주게이션 단위** 필요 → 아조 염료(→Ch11), 카로티노이드가 왜 유색인지.
- Beer-Lambert: A = εcl. 정량 분석 도구.

## MS
- 고에너지 전자 충돌 → 분자 이온 **M⁺•**(라디칼 양이온) + 조각.
- **M⁺•가 분자량**. 동위원소 패턴이 원소를 지목:
  - **M+2가 M과 거의 1:1 → Br**(⁷⁹Br:⁸¹Br ≈ 1:1)
  - **M+2가 M의 약 1/3 → Cl**(³⁵Cl:³⁷Cl ≈ 3:1)
  - M+1 세기 ≈ 1.1% × (탄소 수) → **탄소 개수 추정**
- **질소 규칙**: M⁺•가 **홀수**면 질소가 홀수 개.
- 고분해능 MS(HRMS) → **분자식 확정**.

## 통합 전략(구조 결정의 표준 순서)
1. **MS**: 분자량 → 분자식 → **DoU 계산**(→Ch1).
2. **IR**: 어떤 작용기가 있는가(C=O? O–H? N–H? C≡N?).
3. **¹³C NMR**: 탄소 환경의 개수 → 대칭성.
4. **¹H NMR**: 화학적 이동(환경) + 적분(개수) + 갈라짐(이웃) → **연결성 조립**.
5. 후보 구조를 모든 데이터에 대해 역검증.

## 왜 이 예제인가
- **에탄올 ¹H NMR (三重·四重·單一)**: n+1 규칙과 적분비(3:2:1)를 한 스펙트럼에서 동시에 보여주는 최소 예제. –OH가 갈라지지 않는 예외까지 포함.
- **C=O 파수 사다리(아마이드→아실 클로라이드)**: 분광 데이터가 Ch10의 전자 이론을 독립적으로 확증.
- **Br/Cl 동위원소 패턴**: 스펙트럼의 "모양"이 정성 정보를 직접 준다.
- **β-카로틴**: 콘주게이션 길이와 색의 연결 — UV-Vis가 왜 필요한지.

## ⚠ 원문 교정
1. **"인접 탄소 상에 붙어 있는 다른 nonequivalent 수소들의 정렬 상태에 따라 … n개일 때 n+1개"** — **잘못된 진술.** n+1 규칙은 **서로 등가인(equivalent) 이웃 H가 n개**일 때 성립한다. 이웃 H들이 서로 **비등가**이면 단순 n+1이 아니라 **(n+1)(m+1)…의 다중 갈라짐(dd, ddd 등)**이 나온다. 원문 표현대로 가르치면 실제 스펙트럼 해석이 전부 어긋난다. **이 장에서 가장 심각한 오류.**
2. **"봉우리가 정확히 n+1개로 **대칭 분해**"** — 세기 비는 파스칼 삼각형이지 균등하지 않다. "대칭"이라는 단어가 오해를 부른다.
3. **적분(integration)과 커플링 상수 J가 통째로 누락** — ¹H NMR의 3대 정보(δ, 적분, 갈라짐) 중 하나가 빠졌고, J로 E/Z를 판별하는 실용 기법도 없다.
4. **NMR을 "라디오 주파수 **라디칼** 에너지와 공명"** — 오타 계열 오류. 라디칼이 아니라 **라디오파(radiofrequency)**다.
5. **IR·NMR의 구체적 수치표가 없음** — 분광학 단원인데 판독 기준값이 하나도 없으면 사용 불가.
6. **MS의 동위원소 패턴·질소 규칙 누락** — MS를 "분자량 산출"로만 서술.
7. **통합 해석 전략이 없음** — 각 기법이 병렬 나열될 뿐, 실제 문제 풀이 순서가 제시되지 않는다.
8. **화학적 이동을 "주파수가 밀려 편차가 발생하는 지표"** — ppm이 왜 자기장 무관 단위인지가 빠져 기기 간 비교 가능성의 근거가 없다.

## ⚙ mol-craft 접점
- `[가능→구현 가능, 저비용·고효용]` **화학적 등가성(NMR 신호 개수) 판정**: 분자 그래프의 **자기동형(graph automorphism)**을 구하면 등가 H 집합이 나오고 → **¹H/¹³C 신호 개수**를 예측할 수 있다. Morgan 알고리즘(반복 확장 연결도)으로 근사하면 구현이 가볍다. **양자 계산 없이 순수 그래프 연산으로 가능한 유일한 분광 예측**이며, 대칭성 교육과 직결된다.
- `[가능→구현 가능]` **적분비**: 등가 집합의 크기 = 적분비. 위 판정의 부산물로 공짜.
- `[가능→구현 가능]` **n+1 이웃 계수**: 각 H의 이웃 탄소에 붙은 H 개수 → 다중도 예측(등가/비등가 구분까지 하면 dd·ddd도 가능). **교정 ①의 올바른 규칙을 코드로 강제하면, 학습자가 틀린 n+1을 배울 수 없게 된다.**
- `[가능→구현 가능]` **IR 작용기 판독표**: 부분 그래프 매칭(C=O, O–H, N–H, C≡N)으로 작용기를 검출해 **예상 IR 흡수대를 표로 제시**. 실제 스펙트럼 계산이 아니라 **규칙 기반 판독 연습 도구**로 정직하게 포지셔닝.
- `[가능]` **DoU**(→Ch1) — 통합 전략 1단계를 그대로 지원.
- `[부분]` 화학적 이동 δ **값** 예측: 가법 규칙(Shoolery 등)으로 근사 가능하나 오차가 커서 교육용으로 위험. 신호 **개수·적분·다중도**까지만 하는 것이 정직한 선.
- `[불가]` 실제 스펙트럼 시뮬레이션(NMR 차폐 상수·IR 진동 모드·UV-Vis 전이) — **전부 양자 계산 영역**. UFF의 조화 진동수는 UFF 힘상수에서 나오지만 실측 IR 파수와 맞지 않아 교육용으로 쓸 수 없다.
- **활용 제안**: 이 장은 **"mol-craft에서 그린 구조 → 예상 스펙트럼 특징(신호 개수·적분·다중도·IR 밴드) → 사용자가 맞히기"** 형태의 퀴즈 모드로 만들면 구조-분광 연결 훈련이 된다. 구현 난도는 그래프 알고리즘 수준이고, 양자 계산은 전혀 필요 없다. **학습 플랫폼화에서 비용 대비 효과가 가장 좋은 후보 중 하나.**
