# Ch14. Synthetic Polymers

## Presupposes
Ch2: 라디칼 연쇄 반응(개시/전파/종결), vdW 인력. Ch3: 알켄 첨가, 카보양이온. Ch5: 입체중심, 배치. Ch10: 에스터·아마이드 형성(축합).

## 개념
- **고분자**: 반복 단위(**단량체**)가 공유결합으로 연결된 거대 분자. 중합도 n, 분자량은 **분포**를 가짐(Mn 수평균, Mw 중량평균, **다분산도 PDI = Mw/Mn**).
- 두 가지 중합 방식 — **이 구분이 이 장의 뼈대**:

| | 사슬 성장(부가) | 단계 성장(축합) |
|---|---|---|
| 단량체 | **C=C 함유** | **양단에 작용기 2개** |
| 성장 방식 | 활성 말단에 하나씩 추가 | 아무 두 조각끼리 결합 |
| 부산물 | **없음**(원자 경제 100%) | H₂O, HCl 등 **이탈** |
| 분자량 vs 전환율 | **초기부터 고분자량** | **전환율 99% 넘어야 고분자량** |
| 반응 중 계 | 단량체 + 완성된 고분자 공존 | 이량체·삼량체… 점진 |
| 예 | PE, PP, PS, PVC, PMMA, 테플론 | 나일론, PET, 폴리우레탄, 에폭시 |

## 사슬 성장 중합
- **라디칼 중합**(Ch2 연쇄 반응의 확장): 개시제(과산화벤조일, AIBN) → R• → 단량체에 첨가 → 전파 → 종결(재결합 또는 불균등화).
  - **위치선택성**: 라디칼이 항상 **더 안정한 쪽**에 남도록 첨가 → **head-to-tail 규칙성**.
  - 사슬 이동(chain transfer)으로 **가지(branching)** 발생 → LDPE(가지 많음, 저밀도, 무름) vs HDPE(선형, 고밀도, 단단) — **같은 단량체, 다른 물성**.
- **양이온 중합**: 전자 공여 치환기 단량체(아이소뷰틸렌) — 카보양이온 안정화 필요.
- **음이온 중합**: 전자 끌개 단량체(아크릴로나이트릴, 스타이렌) — 카바니온 안정화. **리빙 중합** 가능 → 좁은 PDI, 블록 공중합체.

## 입체 규칙성(tacticity)
비닐 단량체 CH₂=CHX가 중합하면 X를 가진 탄소마다 입체중심이 생긴다.
- **아이소택틱**: X가 전부 같은 쪽 → **규칙적 → 결정성 ↑ → 강도·융점 ↑**
- **신디오택틱**: 교대 → 역시 규칙적, 결정성 있음
- **어택틱**: 무작위 → **비결정성 → 무르고 투명**
- 폴리프로필렌: 어택틱은 끈적한 물질, 아이소택틱은 실용 플라스틱(mp 160 °C). **물성 차이의 원인이 순전히 입체배치**라는 것이 요점.
- **치글러-나타 촉매**(TiCl₄ + Al(C₂H₅)₃): 금속 중심에 단량체가 배위하며 삽입 → **입체 규칙성 제어**. 1963 노벨상. 메탈로센 촉매가 현대적 후속.

## 단계 성장 중합
- **폴리에스터(PET)**: 테레프탈산 + 에틸렌 글라이콜, 에스터화(→Ch10).
- **폴리아마이드(나일론-6,6)**: 아디프산 + 헥사메틸렌다이아민. **아마이드 결합의 수소결합**이 사슬 간 인력을 만들어 섬유 강도를 낸다(→Ch10 아마이드 평면성 + Ch17 단백질과 같은 화학).
- **가교(cross-linking)**: 3작용기 단량체 → 3차원 망상 → **열경화성**(가열해도 안 녹음). 2작용기만이면 **열가소성**(선형/가지, 가열 시 연화).
- **Carothers 식**: 중합도 Xn = 1/(1−p), p = 전환율 → **p = 0.99여야 Xn = 100**. 단계 성장의 실무적 난점(정확한 화학량론과 고순도 필요)의 근거.

## 물성을 결정하는 축
1. **분자량** ↑ → 사슬 얽힘 ↑ → 강도 ↑
2. **결정성**(규칙성·입체규칙성) ↑ → 강도·불투명도 ↑, 유연성 ↓
3. **사슬 간 인력**(vdW < 쌍극자 < 수소결합) — PE(vdW만) < PVC(쌍극자) < 나일론(수소결합)
4. **가교도** — 고무의 가황(황 가교)이 원형
5. **유리전이온도 Tg / 융점 Tm** — 사용 온도 범위 결정

## 왜 이 예제인가
- **LDPE vs HDPE**: 같은 단량체·같은 결합, **가지 유무만으로** 물성이 갈림 → 구조-물성 상관의 가장 순수한 사례.
- **아이소택틱 vs 어택틱 PP**: 입체화학(Ch5)이 거시 물성으로 직결되는 유일한 대중적 사례.
- **나일론-6,6 계면 중합("나일론 로프 트릭")**: 단계 성장이 두 상 경계에서 즉시 일어나는 시연.
- **Carothers 식**: 왜 축합 중합이 부가 중합보다 어려운지를 수식 하나로 설명.

## ⚠ 원문 교정
1. **단계 성장의 분자량-전환율 관계(Carothers 식)가 없음** — 두 중합 방식의 **가장 실질적인 차이**(초기부터 고분자량 vs 99% 전환 필요)가 빠졌다. 원문은 "서서히 사슬 중합을 완성"이라고만 서술.
2. **양이온/음이온 중합, 리빙 중합 누락** — 사슬 성장을 라디칼 하나로만 설명.
3. **가교·열가소성/열경화성 구분이 없음** — 고분자 물성 이해의 기본 분류.
4. **입체 규칙성이 물성에 미치는 결과가 없음** — 원문은 아이소/신디오/어택틱을 **정의만** 하고 "그래서 무엇이 달라지는가"(결정성·강도)를 말하지 않는다. 정의만 남으면 암기 항목이 된다.
5. **치글러-나타를 "완벽하게 형성해내는"** 등 과장 표현 — 실제로는 촉매 종류·조건에 따라 규칙성 정도가 달라진다. 또한 **왜** 입체 제어가 되는지(금속 배위 자리의 기하)가 없다.
6. **head-to-tail 규칙성의 원인(라디칼 안정성)이 없음** — Ch2·Ch3와 연결되는 지점인데 끊겨 있다.
7. **분자량 분포(PDI) 개념 부재** — 고분자가 단일 분자량 물질이 아니라는 기본 사실.

## ⚙ mol-craft 접점
- `[가능]` **반복 단위 구축**: `model.duplicateAtoms()`가 선택 원자를 2 Å 옆에 복제하고 내부 결합까지 복사한다 → **올리고머 조립의 기본 연산이 이미 있다**. `Ctrl+D`로 단량체를 복제해 결합 도구로 잇는 워크플로가 가능.
- `[가능]` **입체 규칙성 시각화 — 이 장 최고의 활용처**: 아이소택틱/신디오택틱/어택틱 폴리프로필렌 올리고머(5~7량체)를 만들어 `minimize` 후 비교하면
  - 아이소택틱은 **3₁ 나선**으로 감기고, 신디오택틱은 지그재그 평면에 가까워진다 — **UFF의 vdW + 비틀림만으로 실제로 재현되는 현상**이다.
  - `energy().byType.vdw`로 입체 반발 차이를 정량화 가능.
  - **입체배치(Ch5) → 사슬 형태 → 결정성**의 인과를 3D로 보여주는, 교재가 그림으로만 말하는 것을 계산으로 확인시키는 데모.
- `[가능]` **가지 유무(LDPE/HDPE) 비교**: 선형 vs 가지 사슬을 만들어 회전반경(Rg)·최대 치수를 계산하면 "왜 가지가 많으면 밀집 못 하는가"를 정량화. 좌표만으로 계산 가능.
- `[부분]` 실용 사슬 길이: `buildTerms()`의 **vdW 항이 O(n²)**이고 `gradient()`가 항별 중심차분(해석 미분 아님, `uff.js:284` 주석)이라 **수백 원자 이상은 느려진다**. 폴리머 데모는 **올리고머(≤10량체, ~100원자) 규모로 제한**해야 실용적. 코드 주석도 "수천 원자 규모로 키우려면 해석 미분으로 교체"라고 명시.
- `[불가]` 중합 반응 자체, 라디칼·이온 중간체, 분자량 분포, Tg/Tm 등 벌크 물성(단일 분자 모델의 원리적 한계).
- `[불가]` 치글러-나타(Ti·Al 미지원 원소).
- **활용 제안**: "고분자 = 큰 분자"가 아니라 **"반복 단위의 기하가 사슬 형태를 정하고, 사슬 형태가 물성을 정한다"**는 사슬을 3D로 보여주는 것이 mol-craft의 정확한 기여 범위. 벌크 물성은 명시적으로 범위 밖으로 선언할 것.
