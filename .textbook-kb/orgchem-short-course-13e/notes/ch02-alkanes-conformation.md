# Ch2. Alkanes and Cycloalkanes; Conformational and Geometric Isomerism

## Presupposes
Ch1: σ 결합의 자유 회전, sp³ 109.47°, 구조 이성질체, 원자가.

## 개념
- **포화 탄화수소**: C–C, C–H 단일결합만. 알칸 **CₙH₂ₙ₊₂**(비고리), 사이클로알칸 **CₙH₂ₙ**(고리 1개, DoU=1).
- **동족 계열**: –CH₂– 단위씩 차이. 물성이 단조 변화 → 외삽 가능.
- **알킬기 R**: 알칸 − H 1개. 1°/2°/3° 구분은 **그 탄소에 붙은 다른 탄소의 수**로 정의(H 수가 아님).
- **IUPAC 주사슬 규칙**: ① 가장 긴 연속 사슬 ② 치환기 번호 합이 최소가 되도록 번호 매김 ③ 치환기는 알파벳순 ④ 동수면 알파벳 앞선 쪽에 낮은 번호.
- **런던 분산력(반데르발스 인력)**: 순간 쌍극자 ↔ 유도 쌍극자. **접촉 표면적에 비례** — 사슬이 길수록 bp↑, **가지가 많을수록 구형에 가까워져 접촉면적↓ → bp↓**(n-펜탄 36 °C vs 네오펜탄 9.5 °C). 분자량이 같아도 모양이 물성을 가른다.

## 배좌 분석(이 장의 핵심)
- **배좌 이성질체(conformer/rotamer)**: σ 회전으로 상호 전환. 실온에서 장벽이 낮아(≲20 kcal/mol) **분리 불가**. Ch5의 배치 이성질체와 결정적으로 다른 점.
- **엇갈린형(staggered)**: 이면각 60°/180°. 최저 에너지.
- **가려진형(eclipsed)**: 0°/120°. 최고 에너지. **비틀림 스트레인(torsional strain)**.
- **에탄 회전장벽 = 2.9 kcal/mol** (12 kJ/mol), 주기 3(n=3).
- **부탄 C1–C2–C3–C4 이면각 프로파일**(문헌값, 상대 kcal/mol):
  | 이면각 | 배좌 | ΔE |
  |---|---|---|
  | 180° | **anti** | 0 (전역 최소) |
  | ~65° | **gauche** | +0.9 |
  | 120° | eclipsed (CH₃/H) | ~+3.6 |
  | 0° | **syn-periplanar** (CH₃/CH₃) | **~+4.5–6.1** |
  - gauche가 anti보다 높은 이유는 비틀림이 아니라 **입체 반발(steric, 두 메틸의 vdW 겹침)**. 두 원인이 분리되는 첫 사례.

- **사이클로알칸 스트레인 3종**
  1. **각 스트레인(Baeyer)**: 결합각이 109.47°에서 벗어남. 사이클로프로판(60°)·사이클로뷰테인(90°)에서 지배적.
  2. **비틀림 스트레인**: 가려진 C–H.
  3. **입체 스트레인**: 비결합 원자 간 반발(1,3-diaxial, flagpole).
  - 고리 스트레인 총량(kcal/mol): C3 27.5 · C4 26.3 · C5 6.2 · **C6 0** · C7 6.2.
- **의자 형태(chair)**: 각 스트레인 ≈ 0(109.5° 유지) **그리고** 비틀림 스트레인 ≈ 0(모든 인접 C–H 엇갈림). 두 조건을 동시에 만족하는 것이 요점 — 평면 육각형(120°)이 아니라 접혀야 가능.
- **axial(6) / equatorial(6)**: axial은 고리 대칭축에 평행(교대로 위/아래), equatorial은 바깥쪽.
- **고리 뒤집기(ring flip)**: 의자↔의자. **모든 axial ↔ 모든 equatorial 교환**. 장벽 ~10.8 kcal/mol → 실온에서 초당 ~10⁵회, 분리 불가.
- **A-value(치환기의 equatorial 선호 에너지, kcal/mol)**: CH₃ 1.7 · iPr 2.2 · **tBu ~4.9(사실상 고정)** · OH 0.9 · Ph 2.8. 원인은 **1,3-diaxial 상호작용**(axial 치환기와 같은 쪽 C3·C5의 axial H).
- 보트 < twist-boat 순서: chair → **twist-boat +5.5** → boat +6.8(전이상태에 가까움, flagpole 반발 + 완전 가려짐).

## 기하·배치 이성질체
- **기하 이성질체(cis/trans)**: 회전이 막힌 결과(고리 또는 π결합). 상호 전환 불가.
- **배치 이성질체**: **결합을 끊어야만** 전환 가능. 배좌 이성질체와의 경계선이 이 장의 개념적 분수령.
- 판정 규칙: 배좌 = σ 회전으로 도달 가능 / 배치 = 불가능.

## 라디칼 할로젠화
- **자유 라디칼**: 홀전자 1개. 균일 분해(homolysis, 화살표는 낚싯바늘 반쪽).
- **연쇄 반응 3단계**: 개시(X₂ → 2X•, hν/Δ) → 전파(X• + RH → R• + HX; R• + X₂ → RX + X•) → 종결(라디칼끼리 결합).
- **선택성**: 라디칼 안정성 3° > 2° > 1° > CH₃(초공액).
  - Cl• 상대속도 3°:2°:1° ≈ **5:4:1** (반응성 높음 → 비선택적, 이른 전이상태)
  - Br• ≈ **1600:80:1** (반응성 낮음 → 고선택적, 늦은 전이상태)
  - **Hammond 가설**: 발열 반응의 전이상태는 반응물을 닮고, 흡열 반응의 전이상태는 생성물(라디칼 중간체)을 닮는다 → 흡열인 Br•쪽이 중간체 안정성 차이를 그대로 반영해 선택적.

## 왜 이 예제인가
- **에탄**: 스트레인이 비틀림 하나뿐인 최소 사례 → 순수한 torsional 항의 크기를 잰다.
- **부탄**: 여기서 처음 입체 반발이 추가된다 → anti/gauche 차이는 torsion만으로 설명 불가.
- **사이클로헥산 의자**: "각 스트레인과 비틀림 스트레인을 동시에 0으로 만들 수 있다"는 존재 증명.
- **네오펜탄 vs n-펜탄**: 분자량 통제 후 모양만의 효과.

## ⚠ 원문 교정
1. **가려진형의 원인을 "결합 전자쌍 간 정전기적 반발"이라 단정** — 고전적 설명이며 현대 해석은 **엇갈린형이 초공액(σ_C–H → σ*_C–H 비편재화)으로 안정화되기 때문**이라는 쪽이 우세(Pophristic & Goodman, *Nature* 2001). "반발로 불안정" vs "안정화의 부재"는 학습자에게 다른 그림을 준다. 최소한 양쪽을 병기해야 함.
2. **의자 형태를 "가장 안정한 형태"라고만 서술** — axial/equatorial 교환(ring flip)과 A-value가 빠지면 치환 사이클로헥산 문제를 전혀 못 푼다. 원문이 axial/equatorial을 "정의"만 하고 **에너지 결과를 연결하지 않은 것**이 최대 누락.
3. **보트가 두 번째 안정 형태처럼 읽힘** — 실제 국소 최소는 **twist-boat**이고 boat는 그 사이의 전이상태에 가깝다.
4. 라디칼 할로젠화의 **선택성 수치와 Hammond 가설이 통째로 누락**. "라디칼 안정성 서열"만으로는 왜 Br₂가 합성에 쓰이고 Cl₂는 안 쓰이는지 설명 못 함.

- `[가능]` `presets.js`: `ethane` · `butane(anti)` · `cyclohexane_chair` · `cyclohexane_boat` — 이 장의 표준 예제가 프리셋으로 존재.
- `[가능]` `model.setDihedral()` + UI 이면각 슬라이더 = 뉴먼 투영 없이 3D로 배좌를 직접 돌려보는 경로.
- `[부분]` **정량 정확도 격차(중요)**: mol-craft UFF의 부탄 syn 장벽은 **6–14 kcal/mol**로 허용(`validation.test.js:94`), 문헌은 4.5–6.1. gauche도 0.5–3(문헌 0.9), 각도 55–90°(문헌 65°). **정성 순서는 맞고 정량은 과대평가** — 학습 화면에 숫자를 그대로 노출하면 틀린 값을 가르치게 된다. 표시 시 "UFF 근사, 문헌값 병기" 처리 필요.
- `[부분]` 스트레인 분해: `uff.energy()`가 `byType`으로 bond/angle/torsion/vdw/inversion을 **이미 분리 반환**한다 → 각 스트레인(angle) / 비틀림 스트레인(torsion) / 입체 스트레인(vdw)의 3분해를 **화면에 그대로 그릴 수 있다**. 이 장을 가르치기에 이보다 맞는 데이터 구조가 없는데 미노출.
- `[불가→구현 가능]` **ring flip**: 의자↔의자 전환 애니메이션과 axial/equatorial 라벨링. `findRings()`로 6원 고리를 잡고 고리 평면 법선 기준으로 치환기를 분류하면 라벨은 계산 가능. A-value 비교(메틸을 axial/equatorial에 두고 `minimize` 후 ΔE)는 **현재 코드로 바로 실험 가능**.
- `[불가]` 라디칼: 홀전자·균일 분해 표현 불가(`charge`·`radical` 필드 없음). `stability()`는 원자가 미충족을 "경고"로만 처리한다 — 라디칼을 의도적으로 만들 수단이 아니라 조립 미완성 신호로 취급.
- `[불가]` cis/trans 기하 이성질체 판정: 이중결합 주위 치환기 배치를 E/Z로 **분류하는 코드 없음**(2D는 3D z좌표로 쐐기/파선만 그림). → Ch5와 함께 처리할 과제.
